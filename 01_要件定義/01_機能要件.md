## 各機能フロー詳細

### F001: テキスト挿入

1. ユーザーがテキスト選択（対象スコープ：エディタ / プレビュー / Canvas / realclaudian チャット領域）
2. `selection.delayMs`（デフォルト 300ms）後にフローティングポップアップ表示（「Add to Claudian」「Add to TTS」の 2 ボタン）
3. 「Add to Claudian」クリック → realclaudian の `activateView()` → `getView().appendToActiveInput(text)` で挿入
4. realclaudian 未検出・ビュー未準備・挿入失敗時は Notice 警告を表示して終了（NoOp）

### F002: 音声読み上げ

1. テキスト選択 → ポップアップ「Add to TTS」クリック（`tts.enabled=true` 時のみ動作）
2. `tts.engine` に応じて 3 エンジンのいずれかで合成・再生：

| エンジン | 方式 | 音色設定 |
|------|------|------|
| `edge`（デフォルト） | POC_015 claude-tts スキル（`~/.claude/skills/claude-tts/scripts/commands.py`）を python spawn で呼び出す HTTP ブリッジ | `voices.edge.{zh,ja,en}`（デフォルト xiaoxiao / nanami / aria） |
| `webspeech` | ブラウザ標準 Web Speech API | `voices.webspeech.{zh,ja,en}`（デフォルト空=ブラウザ標準） |
| `plachta` | Plachta Cloud VITS（HF Space）へ POST → 1 秒間隔ポーリング（最大 60 回） | `plachta.{speaker, language, speed}`。9 プリセット（ウマ娘/原神/サノバウィッチ × 日中英）、speed 0.5〜2.0、テキスト上限 1000 文字 |

3. 設定タブでエンジン dropdown 切替（音色 dropdown・テストボタン × 3 が連動）
4. v0.6.0 移行：`data.json.tts` の旧フィールド（minimax 一式・平型 voice）を削除し Notice を 1 回表示

> 🗑️ **廃止**：minimax エンジン（v0.6.0）、claudetts/auto エンジン構想、ローカル VITS / anime-tts（v0.7.0 で追加 → v0.8.0 で削除し Plachta Cloud に置換）

### F003: フォルダ参照追加

1. ファイルエクスプローラでフォルダ右クリック（`selection.folderEnabled=true` 時のみメニュー表示）
2. 「Add to Claudian」クリック → `@<フォルダパス> ` を Claudian 入力欄へ挿入

### F004: Office 変換

1. ファイル右クリック → 以下のメニュー：
   - 「Convert to Markdown」（単体変換）
   - 「Convert & Split」（変換 + 分割）
   - 「Convert all (N) to Markdown」（複数選択時の一括変換）
2. Python + markitdown を spawn して変換（`office.pythonPath`、Windows デフォルト `py`）
3. 対象拡張子：`docx / xlsx / pptx / pdf / html / htm / csv`（`office.enabledExtensions` で制御）
4. 出力：frontmatter テンプレート（`{{title}}/{{date}}/{{ext}}/{{sourcePath}}` プレースホルダ）付き MD
5. 同名ファイル衝突時は `office.conflictPolicy`（overwrite / skip / timestamp）に従う
6. `office.showProgressModal=true` 時は進捗モーダル表示、出力先は `office.outputDirOverride` で上書き可能

### F005: 拡張子フィルタ

1. `general.enabled` かつ `whitelist.enabled` 時に CSS を注入
2. `whitelist.extensions[]` に含まれない拡張子のファイルを非表示（`alwaysShowFolders` でフォルダは常時表示）
3. プリセット選択（Obsidian 標準 / Office / 画像 / コード / ALL）
4. data.json の外部変更を watch し、変更時に CSS を再注入 / 除去

### F006: 設定画面

1 ページ内部タブ構成の 7 タブ：

| タブ | 内容 |
|------|------|
| 一般 | プラグイン全体有効化、移行状態表示、移行リセット、Quota 有効化・更新間隔 |
| テキスト挿入 | selection 有効化、フォルダメニュー、delayMs、F009 の型/コンテキストフラグ・除外セレクタ |
| テキスト読み上げ | TTS 有効化、エンジン dropdown、言語別音色、Plachta 設定、テストボタン |
| ファイル変換 | office 設定一式（F004 参照） |
| 拡張子フィルタ | whitelist 設定一式（F005 参照） |
| Chroma | chroma 設定一式（F010 参照） |
| Quota | API キー入力、表示モデル ON/OFF、接続テスト（F011 参照） |

### F007: 設定自動移行

- 旧 `claudian-selection-bridge/data.json` → 新 `selection` / `tts`
- 旧 `vault-office-bridge/data.json` → 新 `office`
- 旧 `_disabled__extension-whitelist/data.json` → 新 `whitelist`
- 旧 `chroma-inspector/data.json` → 新 `chroma`
- 移行は旧プラグインのリネームより先に実施。全項目は正規化（normalize）・クランプを通す
- 一般タブから移行リセット可能（フラグをクリアして再移行）

### F008: 旧プラグイン無効化

1. フラグファイル `.obsidian/.claudian-bridge.legacy-disabled` が存在すればスキップ（1 度だけ実行）
2. `community-plugins.json` から旧 4 プラグイン ID を除去
3. `claudian-selection-bridge` / `vault-office-bridge` / `chroma-inspector` のフォルダを `_disabled__` 接頭辞でリネーム
4. 物理削除は行わない（ユーザー手動）

### F009: オブジェクトコンテキストメニュー

1. Obsidian UI 上の要素を右クリック → 「Add to Claudian」メニュー表示
2. 要素を検査（inspector）し、以下の優先順位で名前を取得：aria-label > data-tooltip-position > title > role+textContent > id+textContent > placeholder > textContent
3. `@object[type]` 形式（name / type / context / selector / path / attributes）に整形して Claudian 入力欄へ挿入
4. 型フィルタ 4 フラグ：`button / input / link / element`（role/tag から正規化）
5. コンテキストフィルタ 6 フラグ：`ribbon / sidebar / modal / settings / menu / workspace`（祖先セレクタから判定）
6. 除外セレクタ（デフォルト：`.cb-popup` `.claudian-popup` `.menu` `.suggestion-container`）に一致する要素ではメニュー非表示

### F010: Chroma DB ブラウザ

1. `chroma.enabled=true`（デフォルト OFF・オプトイン）時のみ view / ribbon / command を登録
2. サイドバー ItemView：パスバー + 検索パネル + コレクション一覧 + 結果カード
3. 検索：クエリ + 絞り込み条件（FilterBuilder）、`defaultNResults`（クランプ範囲あり、デフォルト 5）件取得
4. レコードカード：プレビュー `recordPreviewLength` 文字（デフォルト 240）
5. `enableRawSql=true` 時のみ Raw SQL モーダルを利用可能
6. Python スクリプト（`scriptPath`）経由で Chroma DB にアクセス、進捗モーダル表示

### F011: LLM 残量検知

1. `general.quotaEnabled=true`（デフォルト OFF）時に onload で起動（冪等）
2. 4 プロバイダの残量を取得：
   - **Claude**：`~/.claude/settings.json` から LLM 情報読み取り（5 時間ウィンドウ等）
   - **DeepSeek**：残金（CNY）取得
   - **Kimi / MiniMax**：各社 API で残量取得
3. API キー解決：設定値（`quota.*ApiKey`）優先 → 環境変数フォールバック
4. realclaudian の NewTab ボタン左隣にコンパクトインジケータ表示（アンカー取得は直接プロパティ → セレクタ → 旧 API の 3 経路防御的アクセサ）
5. 信号色：使用率 90% 以上=赤 / 70% 以上=橙 / それ以下=緑 / データ無し=灰。DeepSeek 残金は 100 CNY 以上=緑 / 50 超=橙 / 50 以下=赤
6. `quotaRefreshSec`（10〜600 秒、デフォルト 60、0=自動更新停止）周期で再取得
7. `quotaSwitchSec`（5〜600 秒、デフォルト 5）周期で表示プロバイダをローテーション
8. プロバイダ個別の表示 ON/OFF（`quota.displayModels`）、現在使用中モデルをラベル左隣に表示
9. 設定タブから接続テスト可能（fetch 1 回実行）

### F012: 診断ログ

1. モジュールロード時に診断ログ初期化（`initDiagAuto`）+ グローバルエラーハンドラ設置
2. onload 各ステップ（migration / disable / TTS migration / CSS 注入 / 各機能登録）を diag 記録
3. ロード失敗時の原因特定に使用（`claudian-bridge-load.log` / `debug.log`）

### F013: AI読み上げボタン（v0.16.0）

1. ClaudianChat 入力ツールバー（`.claudian-input-toolbar`）右端に ✨ ボタンを注入
2. クリックで入力欄のテキストを取得し、**Claude Code CLI（`claude -p`）** に「意図を解釈し指令文に整形」するプロンプトを送信（プロンプトは stdin 渡し・30 秒タイムアウト・入力と同一言語を維持）
3. 整形成功時: 入力欄を整形文で**上書き**（`input` イベントを dispatch して realclaudian 内部状態と同期）→ 元文を Notice 表示 → `addTextToTTS` で整形文を読み上げ
4. 整形失敗時（CLI 起動不可・タイムアウト・空応答）: **入力欄を変更せず元文のまま読み上げ** + ⚠️ Notice
5. 読み上げ音声は既存 `tts.engine`（edge / webspeech / plachta）の設定に従う
6. 設定タブの「AI読み上げボタン」トグル（`tts.inputAi.enabled`、既定 true）でボタン表示を無効化可能

> ⚠️ **注意**: 空入力・`tts.enabled=false`（ミュート中）は読み上げず Notice で中断。整形 LLM に **API キーの追加設定は不要**（Claude Code CLI が既存設定を利用）。

### F014: MD 保存ボタン（v0.17.0）

1. 回答ブロック右クリック / ツールバーから Memory 保存モーダル起動
2. 保存先フォルダ選択 + ファイル名自動生成（衝突時は連番付与）
3. `serialize()` で Markdown 形式に整形（frontmatter 付与）→ ファイル書き込み
4. 二重クリックガード（同日内再起動防止）

### F015: TTS 読み上げ仕様統一（v0.17.0）

1. 統合エントリポイント `speakText()` で全経路（selection/autoRead/message/inputAi）を集約
2. タイプ別フィルタ（selection / autoRead / message / inputAi）× 8 項目（絵文字・顔文字・ASCII・短コード・コールアウト・テーブル・コード・思考）を ON/OFF
3. MD ファイル右クリック「Add to TTS」で本文（frontmatter・コード除く）を読み上げ

### F016: EdgeTTS チャンク上限（v0.18.0）

1. `tts.chunkMaxChars` を **エンジン別マップ** `{ edge: 500, webspeech: 140, plachta: 140 }` に変更
2. 既存 `chunkMaxChars`（number・v0.17）は webspeech / plachta に引き継ぎ・edge は 500 に初期化（マイグレーション + クランプ）
3. `addTextToTTS` でエンジン別チャンク上限を解決

### F017: 自動読み上げ「最終回答のみ」ゲート（v0.19.0）

1. `detectFinalAnswerState()` 導入：最後の assistant メッセージが **非空の `.claudian-text-block` 終端**のときのみ読み上げ
2. 途中ターン（思考・ツール実行）は即スキップ・dedup マークを付けない
3. `full` スコープは `.claudian-text-block` のみを構造的に読み連結（思考・ツール除外）
4. `header` フォールバックは思考・ツールブロックを構造的に非表示（二重防護）

### F018: Chroma-fs 仮想フォルダ + RAG 検索（v0.20.0）

1. `chroma-fs.hideInternal` で `chroma_db` 内部を CSS 注入で非表示
2. `chroma-fs.rag` で `chroma_db` 内ドキュメント右クリック → RAG 質問モーダル
3. バックエンド: `word-pdf-rag query.py --json` を実行
4. 既存 `data.json` への破壊的変更なし（`chroma-fs` 未設定時はデフォルト補完）

### F019: 右クリックバックアップ（v0.21.0）

1. ファイルツリー右クリック → 「💾 バックアップ」メニュー → 保存先ダイアログ
2. `backup-runner` で `fs.promises.cp` によるタイムスタンプ付きコピー（YYYYMMDD-HHmmss）
3. 設定画面「一般」タブで `general.backupEnabled`（既定 ON）で ON/OFF 切替可能

### F020: アンダースコアフォルダ非表示（v0.22.0）

1. `whitelist.hideUnderscoreFolders`（既定 ON）で `_` プレフィックスフォルダをファイルエクスプローラから非表示
2. CSS 注入 `data-path*="/_"` で `display:none` 適用
3. 「フォルダは常に表示」設定より優先（`_` フォルダは常に非表示）

### F021: 方案ボタン常時表示（v0.24.0）

1. `general.quickReplyShowAllOptions`（既定 OFF）で 1️⃣〜5️⃣ ボタンを**常に表示**
2. OFF（既定）: 応答に「方案N」がある時のみ動的表示（既存挙動）
3. ON: ツールバー注入時に `cb-hidden` クラスを付与せず常時表示

### F022: クイック返信ボタン全体 ON/OFF（v0.25.0）

1. `general.quickReplyEnabled`（既定 ON）で ✅❌1️⃣〜5️⃣ 全体を有効化/無効化
2. OFF: ツールバーへの注入を停止し、既存ボタンを即時削除
3. ON: 既存挙動（showAllOptions を含む）を維持

### F023: 方案検出パターン拡張（v0.26.0）

1. 「案」（方案なし）表記に対応: `案1`, `案1〜4`, `案2 が推奨` を検出
2. 追加語彙: ja `最優先 N / 第一選択 N / 優先案 N / 優先度 N`、zh `首选 N / 优选 N`、en `best option N / prefer option N`
3. 逆順パターン: `案N が推奨` / `案N をおすすめ` も検出

### F024: TTS エンジン変更（v0.27.0）

1. edge_tts v7.2.8 を `py/edge_tts/` に git subtree で同梱（pip 依存ゼロ）
2. 「Add to TTS」と「AI 自動読上げ」で独立した `auto / ja / zh / en` 言語モード
3. クラウド EdgeTTS（HTTPS POST プロキシ）: `edgeCloud = { serverUrl, authToken, timeout }`
4. クロスプラットフォーム対応: Ubuntu / Linux で `python3` 自動検出 + `SIGTERM → SIGKILL`
5. UI: EdgeTTS モジュール場所に 📂 ボタン（electron `shell.openPath`）

### F025: Thought 読上げ除外強化（v0.27.1）

1. `THINKING_BLOCK_SELECTOR` を `.claudian-thinking-block` 単体から**複数クラスの OR** に拡張
2. 追加: `.claudian-thinking-content` / `.claudian-thinking-header` / `.claudian-thinking-label` / `.claudian-thinking`
3. realclaudian v2.2.4+ の DOM 構造（thinking 内容が子クラスに置かれる）に対応
4. 既存ユーザー（`thinking: false` 既定・手動 OFF）への破壊的変更なし

### F026: 完了報告読上げスクリプト整形（v0.28.0）

1. `report-script.ts`（新規）: ✅ 完了報告 DOM を「タスク完了です。」→ 📢 ヘッダー → 「結論。」→「次のアクション提案です。」のサマリーに整形
2. 成果物・検証結果・参照文献・テーブル・思考・コード・ツール呼び出しは読み上げ対象から除外
