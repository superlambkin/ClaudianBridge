# 📖 技術用語対照表

## 🎯 機能/業務用語

| 用語 | 英語 | 略称 | 定義 |
|------|------|------|------|
| Claudian Bridge | Claudian Bridge | CB | 本プラグイン。4 つの旧プラグインを統合した統合ブリッジ（v0.8.0） |
| Add to Claudian | Add to Claudian | — | 選択テキスト/フォルダ/UI 要素を realclaudian チャット入力欄に挿入する機能（F001/F003/F009） |
| Add to TTS | Add to TTS | — | 選択テキストを音声読み上げする機能（F002） |
| オブジェクトコンテキストメニュー | Object Context Menu | OCM | Obsidian UI 要素右クリックで要素情報を `@object[type]` 形式で挿入（F009） |
| 拡張子ホワイトリスト | Extension Whitelist | EW | ファイル一覧を CSS 注入で拡張子フィルタする機能（F005） |
| LLM 残量検知 | LLM Quota Detection | Quota | Claude / DeepSeek / Kimi / MiniMax の残量を信号色で常時表示（F011） |
| プロバイダローテーション | Provider Rotation | — | 残量インジケータの表示プロバイダを `quotaSwitchSec` 周期で切替える機構 |
| 設定自動移行 | Settings Migration | — | 旧 4 プラグインの data.json を新形式へ自動変換（F007） |

## ⚙️ 技術用語

| 用語 | 英語 | 略称 | 定義 |
|------|------|------|------|
| realclaudian | realclaudian | — | Claudian 本体プラグイン（統合対象外・稼働前提依存）。内部 API `activateView`/`getView`/`appendToActiveInput`/`newTabButtonEl` を利用 |
| edge-TTS | edge-TTS | edge | Microsoft Edge 系 TTS。本プラグインでは POC_015 claude-tts スキル経由で実行 |
| Web Speech API | Web Speech API | webspeech | ブラウザ標準の音声合成 API。音色はブラウザ依存 |
| Plachta Cloud VITS | Plachta VITS (HF Space) | plachta | Hugging Face Space 上のクラウド VITS 音声合成。9 プリセット（ウマ娘/原神/サノバウィッチ × 日中英） |
| VITS | Variational Inference with adversarial learning for end-to-end TTS | VITS | End-to-End 音声合成モデル |
| markitdown | markitdown | — | Microsoft 製 Office/PDF/HTML/CSV → Markdown 変換 Python ライブラリ（F004） |
| Chroma | Chroma DB | — | ベクトルデータベース。F010 でブラウズ・検索対象 |
| ConfigStore | Config Store | — | `core/config-store.ts`。data.json の load/save/watch/close を担う基盤 |
| normalize / validate | Normalize / Validate | — | 設定読み込み時の正規化（デフォルト補完・クランプ）と検証（`core/settings.ts`） |
| CSS 注入 | CSS Injection | — | 拡張子フィルタの実現方式。動的生成 CSS を `<style>` として挿入/除去 |
| `_disabled__` リネーム | `_disabled__` rename | — | 旧プラグイン無効化方式。フォルダ名に接頭辞を付与（物理削除しない） |
| 防御的アクセサ | Defensive Accessor | — | realclaudian 内部構造への複数経路フォールバック参照（R-01 対策） |
| 診断ログ | Diagnostic Log | diag | `core/diag.ts` によるロード各ステップ記録（F012） |
| HF Space | Hugging Face Space | — | Plachta TTS のホスティング先。スリープ・レート制限あり（R-04） |
