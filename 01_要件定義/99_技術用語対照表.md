## ⚙️ 技術用語

| 用語 | 英語 | 略称 | 定義 |
|------|------|------|------|
| realclaudian | realclaudian | — | Claudian 本体プラグイン（統合対象外・稼働前提依存）。内部 API `activateView`/`getView`/`appendToActiveInput`/`newTabButtonEl` を利用 |
| edge-TTS | edge-TTS | edge | Microsoft Edge 系 TTS。v0.24.0 で v7.2.8 を `py/edge_tts/` に git subtree 同梱（pip 依存ゼロ） |
| edge_tts 同梱 | edge_tts Bundled | edge-local | `src/features/tts/` から `py/edge_tts/` を spawn。Linux 対応・SIGTERM→SIGKILL（F024） |
| Web Speech API | Web Speech API | webspeech | ブラウザ標準の音声合成 API。音色はブラウザ依存 |
| Plachta Cloud VITS | Plachta VITS (HF Space) | plachta | Hugging Face Space 上のクラウド VITS 音声合成。9 プリセット（ウマ娘/原神/サノバウィッチ × 日中英） |
| VITS | Variational Inference with adversarial learning for end-to-end TTS | VITS | End-to-End 音声合成モデル |
| markitdown | markitdown | — | Microsoft 製 Office/PDF/HTML/CSV → Markdown 変換 Python ライブラリ（F004） |
| word-pdf-rag | word-pdf-rag | — | Chroma-fs RAG で使う `query.py --json` Python サブプロセス（F018） |
| Claude Code CLI | Claude Code CLI | `claude -p` | stdin 経由で整形プロンプトを渡す外部 CLI。30 秒タイムアウト（F013） |
| Zhipu GLM | Zhipu GLM | Zhipu | F011 の 5 プロバイダ目。非公式 usage API 経由（規約上グレー・R-12 監視中） |
| Chroma | Chroma DB | — | ベクトルデータベース。F010 でブラウズ・検索対象。F018 で RAG 質問 |
| ConfigStore | Config Store | — | `core/config-store.ts`。data.json の load/save/watch/close を担う基盤 |
| normalize / validate | Normalize / Validate | — | 設定読み込み時の正規化（デフォルト補完・クランプ）と検証（`core/settings.ts`） |
| CSS 注入 | CSS Injection | — | 拡張子フィルタ・`_` フォルダ非表示の実現方式。動的生成 CSS を `<style>` として挿入/除去 |
| `_disabled__` リネーム | `_disabled__` rename | — | 旧プラグイン無効化方式。フォルダ名に接頭辞を付与（物理削除しない） |
| 防御的アクセサ | Defensive Accessor | — | realclaudian 内部構造への複数経路フォールバック参照（R-01 対策） |
| 診断ログ | Diagnostic Log | diag | `core/diag.ts` によるロード各ステップ記録（F012）。`debug.mermaid.log` は F030 で追加 |
| HF Space | Hugging Face Space | — | Plachta TTS のホスティング先。スリープ・レート制限あり（R-04） |
| MarkdownRenderer | Obsidian Markdown Renderer | — | F030 で mermaid フェンス描画に使う標準 API（mermaid は非同梱） |
| PlaybackController | Playback Controller | — | F031 で新設。⏸/⏭ が音声本体を実制御。`aborted` フラグで spawn にも停止指示 |
| PlaybackController.aborted | PlaybackController.aborted | — | speakChunks ループ先頭で即 `return false` する明示的な abort フラグ（F031） |
| chunkTextNatural | chunkTextNatural | — | F031 の見出し強制分割チャンク。TTS 本体とハイライト index を完全一致させる |
| scrollPositionPct | scrollPositionPct | — | F031 の自動スクロール位置設定（0〜100・既定 40）。CSS 変数として即時反映 |
| `--cb-md-read-highlight` | CSS 変数 `--cb-md-read-highlight` | — | F028 のハイライト色バインド。SettingTab の hex 入力から即時反映 |
| debug.mermaid.log | debug.mermaid.log | — | F030 の mermaid 描画失敗ログ。プラグイン dir 直下へ追記（diag.ts パターン） |
| tokenRateIntervalMs | tokenRateIntervalMs | — | F027 の更新周期プリセット 100/250/500/1000/2000 ms・既定 250（v0.32.0） |
| tokenRateShowTtft / Current / Avg / Max | tokenRateShowFlags | — | F027 の項目個別表示フラグ（v0.31.0）。既定すべて ON |
| quickReplyShowAllOptions | quickReplyShowAllOptions | — | F021 1️⃣〜5️⃣ 常時表示フラグ（既定 OFF） |
| quickReplyEnabled | quickReplyEnabled | — | F22 クイック返信ボタン全体 ON/OFF フラグ（既定 ON） |
| autoReadReportScript | autoReadReportScript | — | F026 完了報告スクリプト整形 ON/OFF（既定 ON・i18n ja/zh/en） |
| mdReadHighlight | mdReadHighlight | — | F028 の `{ enabled, highlightColor }` 設定オブジェクト |
| mermaidRender | mermaidRender | — | F030 の `general.mermaidRender` 設定（既定 ON） |
