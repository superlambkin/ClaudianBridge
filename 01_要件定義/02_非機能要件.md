## 設計上の制約

| 制約 | 内容 |
|------|------|
| パス解決 | `__dirname` / `process.cwd()` は信用せず `app.vault.adapter.getBasePath()` から解決 |
| 外部プラグイン依存 | realclaudian の内部 API（`activateView` / `getView` / `appendToActiveInput` / `newTabButtonEl`）に依存。防御的アクセサ（複数経路フォールバック）で吸収。realclaudian 更新時は grep 複核が必要 |
| 子プロセス | `shell: true` に args 配列を渡さない（DEP0190）。spawn は `windowsHide: true`。**v0.44.2 で `setTimeout(...).unref()` を optional 呼び出しに変更（Obsidian ブラウザ環境では `setTimeout` が数値を返し `.unref` が存在しないため）** |
| 冪等性 | Quota 登録（`registerClaudeQuota`）は冪等。旧プラグイン無効化はフラグファイルで 1 度だけ。**chat-read-highlight の activate/deactivate は世代トークン（`latestToken`）で冪等。MD 画面 Add to TTS ボタンは `data-cb-add-tts` マーカーで冪等** |
| レイアウトスラスタ防止 | **`scrollIntoView({behavior:'smooth'})` を `requestAnimationFrame` 経由の `behavior:'auto'` に置換（v0.49.1）**。`getBoundingClientRect()` の連続呼び出しは rAF 内に 1 回だけ集約。Forced reflow ピーク 114ms → 53ms |
| OpenVPN 権限 | **管理者権限必須**（route 追加・削除）。非管理者実行時は経路未確立の警告を表示。孤児プロセス回収時は PID 再利用誤殺防止のためプロセス名 `openvpn` 確認 |
| NTFS ジャンクション | Outputs ミラーリングは Windows NTFS ジャンクション。Vault 側実フォルダ既存時はミラー無効化（実フォルダ優先） |
