## NFR 一覧

| 項目 | 指標 / 実装機構 |
|------|------|
| パフォーマンス | 選択ポップアップ遅延 `delayMs` デフォルト 300ms（調整可）、TTS plachta ポーリング 1 秒間隔 × 最大 60 回（タイムアウト 60 秒）、Office 変換は非同期 + 進捗モーダル、Quota 自動更新 10〜600 秒（0=停止）、トークン速度カウンタ更新周期 100〜2000 ms（既定 250 ms）、MD ハイライト anchor マッチングは 2.5 秒以内のコンテンツ出現ポーリング、Edge 先行音声変換はチャンク i 再生中にチャンク i+1 の音声を pre-fetch、Mermaid 描画はチャットメッセージ確定後 1.2s でトリガ |
| 互換性 | Obsidian 1.7.2+ / Desktop only（`isDesktopOnly: true`）/ Windows 優先（pythonPath デフォルト `py`、他 OS は `python3`）/ edge_tts v7.2.8 同梱（pip 依存ゼロ）/ Hugging Face Plachta 9 プリセット（ウマ娘/原神/サノバウィッチ × 日中英） |
| セキュリティ | API キー（DeepSeek / Kimi / MiniMax / Zhipu）は `data.json` 平文保持 + 環境変数フォールバック。外部送信先は各プロバイダ公式 API と Plachta HF Space のみ。Chroma Raw SQL は `enableRawSql` オプトイン（デフォルト OFF）。Mermaid 描画はプラグイン dir 直下 `debug.mermaid.log` のみに書き込み |
| 信頼性 | 旧 data.json 移行は正規化・クランプ経由で安全取り込み。旧プラグインはリネーム無効化（物理削除なし）で復元可能。移行リセット機構あり。realclaudian / claude-tts / Plachta 未導入時は Notice 警告の NoOp で graceful 終了。MD ハイライトは anchor 不一致・空コンテナ時に 1 セッション 1 回 Notice（DevTools 不要）。Mermaid 描画失敗時は元コードブロックへフォールバック +「描画失敗」バッジ |
| 国際化 | 日本語 / 中文 / English 3 言語ラベル対応（`core/i18n.ts`）、MD 読上げ聴き手プロファイル名も ja/zh/en の i18n キー対応 |
| テスタビリティ | vitest ユニットテスト（`tests/` は `src/` とミラー構成、obsidian モジュールはスタブ化）+ 手動 UAT。**vitest 1002 件 PASS**（v0.35.1 時点・typecheck 0） |
| 保守性 | 機能モジュール分割：`features/{selection,tts,office,whitelist,chroma,object,quota,chroma-fs,memory,code-copy-fence,backup,quick-reply,token-rate,mermaid-render,md-read-highlight}/` + `core/` + `legacy/`。設定は `normalize` / `validate` / クランプで一元管理。PlaybackController / Mermaid 描画を独立 feature に分離し機能ごとに ON/OFF 可能 |
| 可観測性 | 診断ログ（`core/diag.ts`：ロード各ステップ記録・グローバルエラーハンドラ・`claudian-bridge-load.log` / `debug.log`）。MD ハイライトは `[cb-md-read-highlight] chunk N of M underline applied / NOT matched` を出力。Mermaid は描画失敗を `debug.mermaid.log` へ追記 |

## v0.30.0〜v0.35.1 拡張指標（NFR-13 〜 NFR-21）

| ID | 区分 | 指標 / 実装機構 |
|:--:|:--:|------|
| NFR-13 | 性能 | F013（AI 読み上げ）: `claude -p` 起動 30 秒タイムアウト・stdin 渡し（CJK クォート問題回避）。整形失敗時は元文のまま読み上げ |
| NFR-14 | 性能 | F015（speakText 統合）+ F016（エンジン別チャンク上限 edge 500 / webspeech 140 / plachta 140）で全経路の TTS レイテンシを統一 |
| NFR-15 | 信頼性 | F017（最終回答ゲート）: `detectFinalAnswerState()` で思考・ツール途中ターンの誤発火を防止 |
| NFR-16 | 信頼性 | F018（Chroma-fs RAG）+ F025（Thought 除外）: 既存ユーザーへの破壊的変更なし、既存 `data.json` への無追加補完 |
| NFR-17 | 性能 | F019（バックアップ）+ F020（`_` フォルダ非表示）: `fs.promises.cp` によるタイムスタンプコピー、CSS 注入で `display:none` 適用 |
| NFR-18 | 性能 | F021/F022/F023（クイック返信方案）: 推奨方案検出をパターン拡張（ja/zh/en）し、誤検出時は動的表示 OFF にフォールバック |
| NFR-19 | 性能 | F024（TTS エンジン変更）: edge_tts 同梱で `pip install` ゼロ、クラウド HTTPS プロキシ・Linux 対応 |
| NFR-20 | 性能 | F027（トークン速度）+ F028（MD ハイライト）+ F030（Mermaid 描画）+ F031（再生制御強化）: それぞれ独立 feature として onload で `general.*` フラグを見て起動スキップ可能 |
| NFR-21 | 信頼性 | F031（PlaybackController）: ⏸/⏭ が音声本体を実制御。スキップで合成中の spawn にも停止指示し「音声生成中」で固まらない |

## 設計上の制約

| 制約 | 内容 |
|------|------|
| パス解決 | `__dirname` / `process.cwd()` は信用せず `app.vault.adapter.getBasePath()` から解決 |
| 外部プラグイン依存 | realclaudian の内部 API（`activateView` / `getView` / `appendToActiveInput` / `newTabButtonEl`）に依存。防御的アクセサ（複数経路フォールバック）で吸収。realclaudian 更新時は grep 複核が必要 |
| 子プロセス | `shell: true` に args 配列を渡さない（DEP0190）。spawn は `windowsHide: true` |
| 冪等性 | Quota 登録（`registerClaudeQuota`）は冪等。旧プラグイン無効化はフラグファイルで 1 度だけ |
