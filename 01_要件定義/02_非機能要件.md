# 📋 非機能要件（As-Built v0.8.0）

> ⚠️ **v2.0.0 改版说明**：実装済み v0.8.0 の実績値・実装機構に基づき全面書き換え（2026-08-13）。

## NFR 一覧

| 項目 | 指標 / 実装機構 |
|------|------|
| パフォーマンス | 選択ポップアップ遅延 `delayMs` デフォルト 300ms（調整可）、TTS plachta ポーリング 1 秒間隔 × 最大 60 回（タイムアウト 60 秒）、Office 変換は非同期 + 進捗モーダル、Quota 自動更新 10〜600 秒（0=停止） |
| 互換性 | Obsidian 1.7.2+ / Desktop only（`isDesktopOnly: true`）/ Windows 優先（pythonPath デフォルト `py`、他 OS は `python3`） |
| セキュリティ | API キー（DeepSeek / Kimi / MiniMax）は `data.json` 平文保持 + 環境変数フォールバック。外部送信先は各プロバイダ公式 API と Plachta HF Space のみ。Chroma Raw SQL は `enableRawSql` オプトイン（デフォルト OFF） |
| 信頼性 | 旧 data.json 移行は正規化・クランプ経由で安全取り込み。旧プラグインはリネーム無効化（物理削除なし）で復元可能。移行リセット機構あり。realclaudian / claude-tts / Plachta 未導入時は Notice 警告の NoOp で graceful 終了 |
| 国際化 | 日本語 / 中文 / English 3 言語ラベル対応（`core/i18n.ts`） |
| テスタビリティ | vitest ユニットテスト（`tests/` は `src/` とミラー構成、obsidian モジュールはスタブ化）+ 手動 UAT |
| 保守性 | 機能モジュール分割：`features/{selection,tts,office,whitelist,chroma,object,quota}/` + `core/` + `legacy/`。設定は `normalize` / `validate` / クランプで一元管理 |
| 可観測性 | 診断ログ（`core/diag.ts`：ロード各ステップ記録・グローバルエラーハンドラ・`claudian-bridge-load.log` / `debug.log`） |

## 入力値クランプ（設定の安全弁）

| 設定項目 | 範囲 | デフォルト |
|------|------|------|
| `general.quotaRefreshSec` | 10〜600 秒（0=自動更新停止） | 60 |
| `general.quotaSwitchSec` | 5〜600 秒 | 5 |
| `tts.plachta.speed` | 0.5〜2.0 | 1.0 |
| Plachta テキスト長 | 最大 1000 文字 | — |
| `chroma.defaultNResults` | MIN〜MAX クランプ（`chroma/defaults.ts` 定義） | 5 |
| `chroma.recordPreviewLength` | MIN〜MAX クランプ（同上） | 240 |
| `selection.delayMs` | 0 以上の整数（validate） | 300 |

## 設計上の制約

| 制約 | 内容 |
|------|------|
| パス解決 | `__dirname` / `process.cwd()` は信用せず `app.vault.adapter.getBasePath()` から解決 |
| 外部プラグイン依存 | realclaudian の内部 API（`activateView` / `getView` / `appendToActiveInput` / `newTabButtonEl`）に依存。防御的アクセサ（複数経路フォールバック）で吸収。realclaudian 更新時は grep 複核が必要 |
| 子プロセス | `shell: true` に args 配列を渡さない（DEP0190）。spawn は `windowsHide: true` |
| 冪等性 | Quota 登録（`registerClaudeQuota`）は冪等。旧プラグイン無効化はフラグファイルで 1 度だけ |
