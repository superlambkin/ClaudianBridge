## 📐 概要

本章は F001-F012 に対し、**Given-When-Then（BDD 風）** 形式で合格基準を定義する（As-Built v0.8.0 実績ベース、2026-08-13 全面改訂）。状態列の ✅ は実装 + 手動 UAT で検証済みを示す。

## 🎯 F001 テキスト挿入

### AC-F001-1 選択テキストの挿入

```
Given  realclaudian が有効で、ノート内テキストを選択している
When   300ms 後に表示されたポップアップの「Add to Claudian」をクリック
Then   - Claudian チャット入力欄に選択テキストが追記される
And    - realclaudian ビューがアクティブ化される
```

### AC-F001-2 realclaudian 未導入時の graceful 終了

```
Given  realclaudian プラグインが存在しない
When   「Add to Claudian」をクリック
Then   - 「⚠️ Claudian プラグインが見つかりません」の Notice が表示される
And    - クラッシュ・例外スローは発生しない
```

## 🎯 F002 音声読み上げ

### AC-F002-1 エンジン別読み上げ

```
Given  tts.enabled=true、エンジンに edge / webspeech / plachta のいずれかを選択
When   選択テキストのポップアップで「Add to TTS」をクリック
Then   - 選択エンジンの方式で音声が合成・再生される
And    - edge は voices.edge.{言語} の音色、plachta は plachta.{speaker,language,speed} が使われる
```

### AC-F002-2 plachta の制約

```
Given  エンジンが plachta
When   1000 文字超のテキスト、または範囲外 speed（0.5〜2.0 外）を設定
Then   - テキストは上限内に制限され、speed はデフォルト 1.0 にフォールバックする
And    - 合成は 60 秒でタイムアウトし Notice 通知される
```

## 🎯 F003 フォルダ参照追加

```
Given  selection.folderEnabled=true
When   ファイルエクスプローラでフォルダを右クリック →「Add to Claudian」
Then   - Claudian 入力欄に `@<フォルダパス> ` が挿入される
```

## 🎯 F004 Office 変換

### AC-F004-1 単体変換

```
Given  office.enabled=true、Python + markitdown が利用可能
When   docx ファイルを右クリック →「Convert to Markdown」
Then   - frontmatter テンプレート付き MD が出力される
And    - 同名既存ファイルは conflictPolicy（overwrite/skip/timestamp）に従って処理される
```

### AC-F004-2 複数選択一括変換

```
Given  対象拡張子のファイルを N 件選択している
When   右クリック →「Convert all (N) to Markdown」
Then   - N 件すべてが変換され、進捗モーダルに件数が表示される
```

## 🎯 F005 拡張子フィルタ

```
Given  whitelist.enabled=true、extensions=[md, pdf]
When   プラグインがロードされる
Then   - ファイル一覧に md / pdf 以外のファイルが非表示になる
And    - alwaysShowFolders=true の場合フォルダは常に表示される
And    - data.json 外部変更時に CSS が再注入される
```

## 🎯 F006 設定画面

```
Given  プラグインが有効
When   設定 → Claudian Bridge を開く
Then   - 7 タブ（一般/テキスト挿入/読み上げ/ファイル変換/拡張子フィルタ/Chroma/Quota）が表示される
And    - 全設定項目の変更が即時 data.json に保存・正規化される
```

## 🎯 F007 / F008 設定移行 + 旧プラグイン無効化

```
Given  旧 4 プラグインの data.json が存在し、.claudian-bridge.legacy-disabled フラグが無い
When   Claudian Bridge が初回ロードされる
Then   - 旧設定が正規化されて新 data.json に取り込まれる
And    - community-plugins.json から旧 4 ID が除去される
And    - 旧フォルダが `_disabled__` 接頭辞でリネームされる（物理削除されない）
And    - 2 回目以降のロードでは再実行されない
```

## 🎯 F009 オブジェクトコンテキストメニュー

```
Given  selection.objectMenuEnabled=true
When   リボンのボタンを右クリック
Then   - 「Add to Claudian」メニューが表示され、クリックで `@object[button]` 形式の要素情報が入力欄に挿入される
And    - 型フラグ OFF の要素種別・除外セレクタ配下ではメニューが表示されない
```

## 🎯 F010 Chroma DB ブラウザ

```
Given  chroma.enabled=true、有効な Chroma DB パスを設定
When   ribbon アイコンまたはコマンドでビューを開き、コレクションを選択して検索
Then   - 結果カードが defaultNResults 件まで表示される
And    - enableRawSql=false の場合 Raw SQL モーダルは利用できない
And    - chroma.enabled=false では view / ribbon / command が一切登録されない
```

## 🎯 F011 LLM 残量検知

### AC-F011-1 インジケータ表示

```
Given  general.quotaEnabled=true、realclaudian が有効、有効な API キーを設定
When   プラグインがロードされる
Then   - realclaudian NewTab ボタン左隣にプロバイダ別インジケータが表示される
And    - 使用率 90% 以上=赤 / 70% 以上=橙 / それ以下=緑 / 取得失敗=灰 で色分けされる
```

### AC-F011-2 ローテーションと更新

```
Given  複数プロバイダの表示が ON
When   quotaSwitchSec（デフォルト 5 秒）が経過
Then   - 表示プロバイダがローテーションする
And    - quotaRefreshSec（デフォルト 60 秒）ごとに残量が再取得される
```

## 🎯 F012 診断ログ

```
Given  プラグインをロード
When   onload 各ステップが実行される
Then   - 診断ログに各ステップ（migration / disable / CSS 注入 / 機能登録）が記録される
And    - 未捕捉例外がグローバルエラーハンドラで捕捉・記録される
```
