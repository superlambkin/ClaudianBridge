## 📐 概要

本章は F001〜F031（F029 欠番・30 機能）に対し、**Given-When-Then（BDD 風）** 形式で合格基準を定義する（As-Built v0.35.1 実績ベース、2026-09-05 同期）。状態列の ✅ は実装 + 手動 UAT + vitest 1002 件で検証済みを示す。

## 🎯 F001 テキスト挿入

### AC-F001-1 選択テキストの挿入

```
Given  realclaudian が有効で、ノート内テキストを選択している
When   300ms 後に表示されたポップアップの「Add to Claudian」をクリック
Then   - Claudian チャット入力欄に選択テキストが追記される
And    - realclaudian ビューがアクティブ化される
```

### AC-F001-2 realclaudian 未導入時の graceful 終了

```
Given  realclaudian プラグインが存在しない
When   「Add to Claudian」をクリック
Then   - 「⚠️ Claudian プラグインが見つかりません」の Notice が表示される
And    - クラッシュ・例外スローは発生しない
```

## 🎯 F002 音声読み上げ

### AC-F002-1 エンジン別読み上げ

```
Given  tts.enabled=true、エンジンに edge / webspeech / plachta のいずれかを選択
When   選択テキストのポップアップで「Add to TTS」をクリック
Then   - 選択エンジンの方式で音声が合成・再生される
And    - edge は voices.edge.{言語} の音色、plachta は plachta.{speaker,language,speed} が使われる
```

### AC-F002-2 plachta の制約

```
Given  エンジンが plachta
When   1000 文字超のテキスト、または範囲外 speed（0.5〜2.0 外）を設定
Then   - テキストは上限内に制限され、speed はデフォルト 1.0 にフォールバックする
And    - 合成は 60 秒でタイムアウトし Notice 通知される
```

## 🎯 F003 フォルダ参照追加

```
Given  selection.folderEnabled=true
When   ファイルエクスプローラでフォルダを右クリック →「Add to Claudian」
Then   - Claudian 入力欄に `@<フォルダパス> ` が挿入される
```

## 🎯 F004 Office 変換

### AC-F004-1 単体変換

```
Given  office.enabled=true、Python + markitdown が利用可能
When   docx ファイルを右クリック →「Convert to Markdown」
Then   - frontmatter テンプレート付き MD が出力される
And    - 同名既存ファイルは conflictPolicy（overwrite/skip/timestamp）に従って処理される
```

### AC-F004-2 複数選択一括変換

```
Given  対象拡張子のファイルを N 件選択している
When   右クリック →「Convert all (N) to Markdown」
Then   - N 件すべてが変換され、進捗モーダルに件数が表示される
```

## 🎯 F005 拡張子フィルタ

```
Given  whitelist.enabled=true、extensions=[md, pdf]
When   プラグインがロードされる
Then   - ファイル一覧に md / pdf 以外のファイルが非表示になる
And    - alwaysShowFolders=true の場合フォルダは常に表示される
And    - data.json 外部変更時に CSS が再注入される
```

## 🎯 F006 設定画面

```
Given  プラグインが有効
When   設定 → Claudian Bridge を開く
Then   - 8 タブ（一般/テキスト挿入/読み上げ/ファイル変換/拡張子フィルタ/Chroma/Quota/Memory）が表示される
And    - 全設定項目の変更が即時 data.json に保存・正規化される
```

## 🎯 F007 / F008 設定移行 + 旧プラグイン無効化

```
Given  旧 4 プラグインの data.json が存在し、.claudian-bridge.legacy-disabled フラグが無い
When   Claudian Bridge が初回ロードされる
Then   - 旧設定が正規化されて新 data.json に取り込まれる
And    - community-plugins.json から旧 4 ID が除去される
And    - 旧フォルダが `_disabled__` 接頭辞でリネームされる（物理削除されない）
And    - 2 回目以降のロードでは再実行されない
```

## 🎯 F009 オブジェクトコンテキストメニュー

```
Given  selection.objectMenuEnabled=true
When   リボンのボタンを右クリック
Then   - 「Add to Claudian」メニューが表示され、クリックで `@object[button]` 形式の要素情報が入力欄に挿入される
And    - 型フラグ OFF の要素種別・除外セレクタ配下ではメニューが表示されない
```

## 🎯 F010 Chroma DB ブラウザ

```
Given  chroma.enabled=true、有効な Chroma DB パスを設定
When   ribbon アイコンまたはコマンドでビューを開き、コレクションを選択して検索
Then   - 結果カードが defaultNResults 件まで表示される
And    - enableRawSql=false の場合 Raw SQL モーダルは利用できない
And    - chroma.enabled=false では view / ribbon / command が一切登録されない
```

## 🎯 F011 LLM 残量検知

### AC-F011-1 インジケータ表示

```
Given  general.quotaEnabled=true、realclaudian が有効、有効な API キーを設定
When   プラグインがロードされる
Then   - realclaudian NewTab ボタン左隣にプロバイダ別インジケータが表示される
And    - 使用率 90% 以上=赤 / 70% 以上=橙 / それ以下=緑 / 取得失敗=灰 で色分けされる
```

### AC-F011-2 ローテーションと更新

```
Given  複数プロバイダの表示が ON
When   quotaSwitchSec（デフォルト 5 秒）が経過
Then   - 表示プロバイダがローテーションする
And    - quotaRefreshSec（デフォルト 60 秒）ごとに残量が再取得される
```

## 🎯 F012 診断ログ

```
Given  プラグインをロード
When   onload 各ステップが実行される
Then   - 診断ログに各ステップ（migration / disable / CSS 注入 / 機能登録）が記録される
And    - 未捕捉例外がグローバルエラーハンドラで捕捉・記録される
```

## 🎯 F013 AI 読み上げボタン

```
Given  tts.enabled=true、tts.inputAi.enabled=true、ClaudianChat 入力欄に任意のテキストが入力されている
When   入力ツールバー右端の ✨ ボタンをクリック
Then   - claude -p が stdin 経由で 30 秒以内に起動し、入力と同一言語の整形文を返す
And    - 整形成功時: 入力欄が整形文で上書きされ、addTextToTTS で読み上げが走る
And    - 整形失敗時: 入力欄は変更されず元文が読み上げられ、⚠️ Notice が表示される
```

## 🎯 F014 MD 保存ボタン

```
Given  F013 等の LLM 回答ブロックが表示されている
When   回答ブロック右クリック →「MD 保存」またはツールバーの保存ボタンをクリック
Then   - フロントマター付き Markdown が保存先フォルダへ書き込まれる
And    - ファイル名衝突時は連番付与でスキップせず保存される
And    - 同日内の二重クリックはガードされ再保存されない
```

## 🎯 F015 TTS 読み上げ仕様統一

```
Given  tts 配下の 8 項目（絵文字・顔文字・ASCII・短コード・コールアウト・テーブル・コード・思考）の ON/OFF
When   speakText() を任意の経路（selection/autoRead/message/inputAi）から呼び出す
Then   - どの経路からも同じ 8 項目フィルタとチャンク分割が共通適用される
And    - MD ファイル右クリック「Add to TTS」では frontmatter・コードブロックを除いた本文が読み上げ対象になる
```

## 🎯 F016 EdgeTTS チャンク上限

```
Given  tts.chunkMaxChars = { edge: 500, webspeech: 140, plachta: 140 }
When   addTextToTTS がエンジン別にチャンク分割を行う
Then   - edge は 500 字、webspeech / plachta は 140 字を超えるチャンクを生成しない
And    - 既存 v0.17 の number 値（webspeech / plachta に継承）は normalize で自動補完される
```

## 🎯 F017 自動読み上げ最終回答のみ

```
Given  マルチターンタスクで思考・ツール実行中の中間応答が到着している
When   extractReportText / auto-read フックが応答を処理する
Then   - 最終 assistant メッセージの `.claudian-text-block` 終端が空でないときのみ読み上げが走る
And    - 途中ターンでは即スキップされ、dedup マークも付与されない
And    - full スコープは thinking / tool ブロックを構造的に除外して連結する
```

## 🎯 F018 Chroma-fs RAG 検索

```
Given  chroma-fs.hideInternal=true、chroma-fs.rag が有効な chroma_db がある
When   chroma_db 内のドキュメントを右クリック →「RAG 検索」
Then   - 質問モーダルが開き、word-pdf-rag query.py --json がバックエンドで実行される
And    - 既存 data.json に破壊的変更は入らず、未設定キーはデフォルト補完される
```

## 🎯 F019 右クリックバックアップ

```
Given  general.backupEnabled=true（既定 ON）、ファイルツリーに 1 ファイル以上
When   ファイル/フォルダを右クリック →「💾 バックアップ」
Then   - 保存先ダイアログが開き、選択先に YYYYMMDD-HHmmss 付きで fs.promises.cp される
And    - 一般タブで general.backupEnabled=false にするとメニュー項目自体が消える
```

## 🎯 F020 アンダースコアフォルダ非表示

```
Given  whitelist.hideUnderscoreFolders=true（既定 ON）
When   プラグインがロードされファイル一覧が描画される
Then   - data-path*="/_" 配下のフォルダが display:none で非表示になる
And    - 「フォルダは常に表示」設定より優先され _ フォルダは常時隠れる
```

## 🎯 F021 方案ボタン常時表示

```
Given  general.quickReplyShowAllOptions=true
When   ClaudianChat のツールバーが描画される
Then   - 1️⃣〜5️⃣ ボタンが応答本文に「方案N」が無くても常時表示される（cb-hidden クラスを付与しない）
And    - false（既定）時は応答に「方案N」を検出した場合のみ動的表示する
```

## 🎯 F022 クイック返信ボタン全体 ON/OFF

```
Given  general.quickReplyEnabled=false
When   ツールバーが再描画される
Then   - ✅❌1️⃣〜5️⃣ ボタンが一切注入されず、既存のボタンも即時削除される
And    - true（既定）時: showAllOptions を含む既存挙動を維持する
```

## 🎯 F023 方案検出パターン拡張

```
Given  LLM 応答に「案1 が推奨」「第一選択 2」「best option 3」等の表記が含まれる
When   auto-read または完了報告読み上げ経路で extractRecommendedOption / extractMaxOptionCount が走る
Then   - 表記ゆれに関わらず案番号が検出され、推奨方案ハイライトが点灯する
And    - 「案」表記（方案番号なし）でも案1, 案1〜4, 案2 が推奨 等を検出する
```

## 🎯 F024 TTS エンジン変更

```
Given  tts.engine = edge-local（pip 依存ゼロの同梱版）/ edge-cloud（HTTPS プロキシ）
When   ユーザーが TTS 設定で engine を切り替える
Then   - edge_local: py/edge_tts/ 内の v7.2.8 同梱版が呼び出され、pip install なしで再生される
And    - edge-cloud: edgeCloud = { serverUrl, authToken, timeout } で HTTPS POST され再生される
And    - Ubuntu / Linux 環境では python3 自動検出・SIGTERM→SIGKILL の順で停止する
```

## 🎯 F025 Thought 読上げ除外強化

```
Given  realclaudian v2.2.4+ のチャット DOM に .claudian-thinking-content / -header / -label / -thinking の子クラスが含まれる
When   TTS 抽出（extractReportText / auto-read）が DOM 走査する
Then   - THINKING_BLOCK_SELECTOR の OR 条件にヒットする全要素が読み上げから除外される
And    - 既存ユーザー（thinking: false 既定・手動 OFF）の挙動は変わらない
```

## 🎯 F026 完了報告読上げスクリプト整形

```
Given  tts.autoReadReportScript=true（既定 ON）、✅ 完了報告 DOM が描画されている
When   extractReportText が完了報告を検出する
Then   - 「タスク完了です。」「[タイトル]」「結論。」「次のアクション提案です。」のみが抽出され読み上げられる
And    - 成果物 / 検証結果 / 参照文献 / 表 / 思考 / コード / ツール呼び出しは読み上げ対象から除外される
And    - 非完了報告・整形失敗時は全文読み上げにフォールバックする
```

## 🎯 F027 トークン速度（tok/s）表示

```
Given  general.tokenRateEnabled=true、項目 4 値（首/現在/平均/最大）の個別 ☑ 設定と intervalMs プリセットが設定済み
When   LLM 応答のストリームが完了する
Then   - カウンタが YOLO トグル左・右寄せで 4 値（ttft/current/avg/max）を表示する
And    - intervalMs 変更で data-interval が新値になり、counter が破棄・再注入される
And    - 100/250/500/1000/2000 ms のいずれかにクランプされ、既定 250 ms で動作する
```

## 🎯 F028 MD 読み上げ位置ハイライト

```
Given  tts.mdReadHighlight.enabled=true、MD ファイルが Preview モードで開かれている
When   MD ファイル右クリック「Add to TTS」で再生開始
Then   - チャンク i の本文位置に amber 下線（CSS 変数 --cb-md-read-highlight）が描画され、フローティングオーバーレイに N/M 進捗が表示される
And    - ⏸ で音声が停止し、▶ で再開する
And    - anchor 不一致・空コンテナ時は 1 セッション 1 回 Notice が出る（DevTools 不要）
```

## 🎯 F030 チャット内 Mermaid 自動描画

```
Given  general.mermaidRender=true（既定 ON）
When   チャットメッセージ内に閉じた mermaid フェンスブロックが現れる
Then   - 1.2s の確定判定後に Obsidian 標準 MarkdownRenderer で自動描画される
And    - 描画後のコードは「</>」ボタンで図 ⇔ コード切替できる
And    - 描画失敗時は元コードへフォールバック +「描画失敗」バッジ + debug.mermaid.log 追記
```

## 🎯 F031 MD 読み上げ再生制御強化

```
Given  tts.mdReadHighlight.enabled=true、MD を Preview モードで再生中
When   フローティングオーバーレイの ⏸ / ⏭ を押下する
Then   - ⏸ で PlaybackController 経由で音声本体が一時停止、▶ で再開する
And    - ⏭ で次の見出し境界のチャンクへスキップし、ハイライトも追従する
And    - スキップで合成中のローカル音声 spawn にも停止指示が出る（v0.35.1 で「音声生成中」固まり解消）
And    - highlightColor は 16 色パレット（通常 8 + 濃い 8）+ カスタムピッカーから選べる
```
