## 📐 概要

本章は Claudian Bridge v0.8.0 の **既知リスク** を体系化する（As-Built 実績ベース、2026-08-13 全面改訂）。リスクは「技術」「外部依存」「業務」「運用」のカテゴリに分類し、各リスクに「ID / 説明 / 影響度 / 発生確率 / リスク値 / 対策 / 責任者 / 状態」の属性を割り当てる。

---

## 🎯 リスクマトリックス説明

各リスクの影響度（Impact）と発生確率（Probability）は **1〜5 の 5 段階評価** を用い、リスク値 = 影響度 × 発生確率 とする。

| 影響度 | 説明 | 確率 | 説明 |
|:----:|------|:----:|------|
| 1 | 極めて低い（リリースに影響なし） | 1 | 極めて低い（< 5%） |
| 2 | 低い（軽微な遅延） | 2 | 低い（5-20%） |
| 3 | 中（顕著な手戻り） | 3 | 中（20-50%） |
| 4 | 高い（機能欠陥） | 4 | 高い（50-80%） |
| 5 | 極めて高い（プロジェクト失敗） | 5 | 極めて高い（> 80%） |

| リスク値 | レベル | 色 | 対応 |
|:-----:|:----:|:----:|------|
| 1-4 | 低 | 🟢 | 承認 |
| 5-9 | 中 | 🟡 | 緩和 + 監視 |
| 10-15 | 高 | 🟠 | 即座に緩和 + エスカレーション |
| 16-25 | 極めて高 | 🔴 | 緊急エスカレーション + 事前計画の発動 |

## 🔴 技術リスク（Tech Risk）

### R-01: realclaudian 内部 API 依存

| 属性 | 内容 |
|------|------|
| **影響度** | 4 |
| **確率** | 3 |
| **リスク値** | 12 🟠 |
| **説明** | F001/F003/F009/F011 が realclaudian の非公開内部 API（`activateView` / `getView` / `appendToActiveInput` / `newTabButtonEl`）に依存。realclaudian は minify bundle のためバージョンアップでプロパティ名・構造が変わりうる |
| **影響** | 挿入機能（F001/F003/F009）と残量表示（F011）が同時に機能不全になる |
| **対策** | 防御的アクセサ（直接プロパティ → セレクタ → 旧 API の 3 経路フォールバック）実装済み。realclaudian 更新時は grep で複核する運用ルール化済み（学習記録 2026-08-04） |
| **責任者** | MiuMiu 🐾 |
| **状態** | 🟡監視中 |

### R-02: 旧プラグイン設定移行の失敗・設定喪失

| 属性 | 内容 |
|------|------|
| **影響度** | 4 |
| **確率** | 2 |
| **リスク値** | 8 🟡 |
| **説明** | 旧 4 プラグインの data.json 形式差異・破損により移行が失敗する可能性 |
| **影響** | ユーザーの既存設定が失われ、再設定が必要になる |
| **対策** | ①全項目を normalize/クランプ経由で取り込み ②旧プラグインは物理削除せず `_disabled__` リネーム（復元可能）③一般タブに移行リセット機構 ④TTS 移行（v0.6.0）も 1 回 Notice 付きで冪等 |
| **責任者** | MiuMiu 🐾 |
| **状態** | 🟢緩和済み |

### R-03: Windows 固有実装の他 OS 非互換

| 属性 | 内容 |
|------|------|
| **影響度** | 2 |
| **確率** | 3 |
| **リスク値** | 6 🟡 |
| **説明** | pythonPath デフォルト `py`（Windows ランチャー）、spawn `windowsHide`、パス区切りなど Windows 前提の実装が散在 |
| **影響** | macOS / Linux で F004（Office 変換）・F010（Chroma）・F002 edge エンジンが動作しない可能性 |
| **対策** | `process.platform` 分岐で `python3` フォールバック実装済み。現運用は Windows のみのため低優先 |
| **責任者** | MiuMiu 🐾 |
| **状態** | 🟢承認（Windows 専用運用） |

## 🌐 外部依存リスク（External Dependency Risk）

### R-04: Plachta HF Space の可用性・仕様変更

| 属性 | 内容 |
|------|------|
| **影響度** | 3 |
| **確率** | 3 |
| **リスク値** | 9 🟡 |
| **説明** | F002 plachta エンジンが外部無料クラウド（Hugging Face Space）に依存。スリープ・レート制限・API 仕様変更がありうる |
| **影響** | plachta エンジンのみ読み上げ不可（edge / webspeech は継続利用可） |
| **対策** | ポーリング最大 60 回（60 秒）でタイムアウト、失敗時は Notice 通知。代替エンジン 2 択を常時保持 |
| **責任者** | MiuMiu 🐾 |
| **状態** | 🟡監視中 |

### R-05: LLM プロバイダ API の仕様変更・レート制限

| 属性 | 内容 |
|------|------|
| **影響度** | 3 |
| **確率** | 3 |
| **リスク値** | 9 🟡 |
| **説明** | F011 が DeepSeek / Kimi / MiniMax の残量 API（非公式含む）に依存。仕様変更やキー失効で取得失敗しうる |
| **影響** | 該当プロバイダの残量表示がグレー（データ無し）になるのみ。本体機能は無影響 |
| **対策** | プロバイダごとに独立した adapter 構造（`quota/providers/*.ts`）、取得失敗はグレー表示で graceful 降解。更新間隔 10〜600 秒で API 負荷を制御 |
| **責任者** | MiuMiu 🐾 |
| **状態** | 🟡監視中 |

### R-06: Python / markitdown 環境未構築

| 属性 | 内容 |
|------|------|
| **影響度** | 3 |
| **確率** | 2 |
| **リスク値** | 6 🟡 |
| **説明** | F004・F010・F002(edge) がローカル Python 環境に依存。未インストール・PATH 未通しで実行失敗 |
