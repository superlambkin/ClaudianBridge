## 📐 概要

本章は Claudian Bridge v0.49.1 の **既知リスク** を体系化する（As-Built 実績ベース、2026-09-15 v0.49.1 同期）。リスクは「技術」「外部依存」「業務」「運用」「OpenVPN」「LLM 残量」「TTS ハイライト」のカテゴリに分類し、各リスクに「ID / 説明 / 影響度 / 発生確率 / リスク値 / 対策 / 責任者 / 状態」の属性を割り当てる。

## 🎯 リスクマトリックス説明

各リスクの影響度（Impact）と発生確率（Probability）は **1〜5 の 5 段階評価** を用い、リスク値 = 影響度 × 発生確率 とする。

| 影響度 | 説明 | 確率 | 説明 |
|:----:|------|:----:|------|
| 1 | 極めて低い（リリースに影響なし） | 1 | 極めて低い（< 5%） |
| 2 | 低い（軽微な遅延） | 2 | 低い（5-20%） |
| 3 | 中（顕著な手戻り） | 3 | 中（20-50%） |
| 4 | 高い（機能欠陥） | 4 | 高い（50-80%） |
| 5 | 極めて高い（プロジェクト失敗） | 5 | 極めて高い（> 80%） |

| リスク値 | レベル | 色 | 対応 |
|:-----:|:----:|:----:|------|
| 1-4 | 低 | 🟢 | 承認 |
| 5-9 | 中 | 🟡 | 緩和 + 監視 |
| 10-15 | 高 | 🟠 | 即座に緩和 + エスカレーション |
| 16-25 | 極めて高 | 🔴 | 緊急エスカレーション + 事前計画の発動 |

|------|------|

| **確率** | 3 |

| **責任者** | MiuMiu 🐾 |
| **状態** | 🟢緩和済み（v0.44.0） |

### R-16: VPN 切断後の残骸経路による通信ブラックホール化

| **責任者** | MiuMiu 🐾 |

| **対策** | **v0.49.1 ホットフィックス**で `scrollIntoView` を `requestAnimationFrame` 経由の `behavior:'auto'` 化、MD 側も同じく rAF 内に `getBoundingClientRect` を 1 回だけ集約。**ピーク 114ms → 53ms・平均 60-80ms → 32-37ms に削減**。根本対策は次 PR で Performance 計測 → 別経路の reflow 犯人特定 |
| **責任者** | MiuMiu 🐾 |
| **状態** | 🟡監視中（v0.49.1 で実用レベル・根本対策は次セッション） |
