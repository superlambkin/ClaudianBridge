## 一、プロジェクト背景

Obsidian のナレッジベース × Claude Code CLI（realclaudian プラグイン）を **テキスト/TTS/RAG の 3 軸で橋渡し** する統合プラグイン。既存の 4 プラグイン（claudian-selection-bridge / vault-office-bridge / extension-whitelist / chroma-inspector）を **1 プラグインに統合** し、設定・移行・無効化を自動化することでユーザー導入コストを最小化する。v0.16.0 以降は AI 整形読み上げ・MD 保存・Chroma 仮想フォルダ等の高機能化を進め、v0.27.1 では realclaudian v2.2.4+ の DOM 構造変更に追従した防御的拡張までを実装。v0.30〜v0.35 でトークン速度表示（F027）・MD 読み上げ位置ハイライト（F028）・チャット内 Mermaid 自動描画（F030）・MD 読み上げ再生制御強化（F031）を実装し、v0.35.1（2026-09-04）で安定化。さらに v0.37〜v0.49 で **完了報告スクリプト整形の堅牢化**（F033）・**LLM 残量 5 プロバイダ**（F011/F048）・**OpenVPN 統合**（F041/F043/F044/F045/F046/F047）・**Outputs フォルダミラリング**（F049）・**🤖 Think モード選択**（F039/F040）を追加し、v0.49.0 で **チャット読上げハイライト**（F050）・**MD 画面 Add to TTS ボタン**（F051）を実装、v0.49.1（2026-09-15）で Forced reflow 嵐の緊急対応を行いホットフィックスとして公開。

## 五、リスク評価

| # | リスク | 影響 | 緩和策 |
|:-:|--------|:----:|--------|
| R-01 | realclaudian の DOM 構造変更で読み上げ・挿入が壊れる | High | F017（最終回答ゲート）・F025（複数クラス OR）で防御的拡張、Thought 除外強化 |
| R-02 | TTS エンジン依存（Python spawn / 外部 API）で起動失敗 | High | Notice 警告の NoOp、graceful 終了、フォールバック 3 エンジン・F048 で Zhipu 純 TS 化 |
| R-03 | Chroma DB のスキーマ・パス変更で RAG が動作不能 | Medium | `enableRawSql` オプトイン、デフォルト OFF、Notice で警告 |
| R-04 | 4 プラグイン移行時のデータ欠落 | Medium | 旧プラグインを物理削除せずリネームのみ、移行リセット機能 |
| R-05 | ドキュメント陳腐化（19 ver 分のずれ） | High | 再発防止フロー（git tag + VERSION 調査 + F-番号マスター + 半自動同期スクリプト + release 規約） |
| R-06 | API キー（DeepSeek / Kimi / MiniMax / Zhipu）の漏洩 | Medium | data.json 平文保持だが環境変数フォールバック対応 |
| R-07 | OpenVPN 切断後に経路が残骸として残り通信不能 | High | F045（検知）・F046（手動削除）・F047（自動削除）の 3 段防御 |
| R-08 | OpenVPN が孤児プロセスとして残存し TAP アダプタを占有 | High | F041（`reapOrphanOpenVpn`）で `--writepid` ファイル + auth マーカーの 2 経路で自動回収 |
| R-09 | Obsidian 非管理者実行で VPN 経路が確立できない | Medium | F044.1（F041 副次）で「管理者として実行してください」Notice + ネットワークタブ警告 |
| R-10 | chat-read-highlight の `scrollIntoView({smooth})` が Forced reflow 嵐を起こす | High | **v0.49.1 ホットフィックス**で `requestAnimationFrame` + `behavior:'auto'` 化（ピーク 114ms → 53ms）。F028 側も同時パッチ |
