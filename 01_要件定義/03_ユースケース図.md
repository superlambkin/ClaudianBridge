## 補助説明

| UC | トリガー | 主な依存先 |
|------|------|------|
| F001 / F002 | テキスト選択 → 遅延ポップアップ（300ms） | realclaudian / edge_tts・WebSpeech・Plachta |
| F003 / F009 | 右クリック（フォルダ / UI 要素） | realclaudian |
| F004 | ファイル右クリック（単体/分割/複数選択） | Python + markitdown |
| F005 | 自動（onload 時 CSS 注入） | なし |
| F006 | 設定タブ → ClaudianBridge を開く（**11 タブ**） | ConfigStore（`data.json`） |
| F007 / F008 | 自動（初回 onload、フラグで 1 度だけ） | 旧 4 プラグインの data.json |
| F010 | ribbon / コマンド（`chroma.enabled=true` 時のみ） | Chroma DB（Python スクリプト経由） |
| F011 | 自動（`quotaEnabled=true` 時に onload 起動） | realclaudian（表示アンカー）、**5 社 API（v0.48.0 で Zhipu 純 TS 化）** |
| F012 | 自動（モジュールロード時） | なし |
| F013 | 入力ツールバー ✨ ボタンクリック | Claude Code CLI（`claude -p`、30s タイムアウト） |
| F014 | 回答ブロック右クリック / ツールバー | Vault ファイルシステム |
| F015 | あらゆる TTS 経路（selection/autoRead/message/inputAi） | 既存エンジン設定 |
| F016 | エンジン別チャンク上限の解決 | エンジン別 `{ edge:500 / webspeech:140 / plachta:140 }` |
| F017 | マルチターンタスク応答の最終到着 | DOM 終端検出（`.claudian-text-block`） |
| F018 | `chroma_db` 内ドキュメント右クリック | Python `word-pdf-rag query.py --json` |
| F019 | ファイルツリー右クリック → 💾 バックアップ | `fs.promises.cp` |
| F020 | ファイル一覧の onload | CSS 注入（`display:none` for `data-path*="/_"`） |
| F021 / F022 / F023 | チャット応答受信 | quickReply 設定 + LLM 応答テキスト |
| F024 | 設定画面 TTS タブのエンジン dropdown | edge_tts 同梱（pip 依存ゼロ）/ HTTPS プロキシ / Linux |
| F025 | 自動（TTS 抽出） | realclaudian v2.2.4+ DOM 構造（thinking 系クラス） |
| F026 | タスク完了報告の DOM 抽出 | `tts.autoReadReportScript` |
| F027 | 自動（LLM 応答ストリーム計測） | `data-interval` 属性 + rescan |
| F028 | MD「Add to TTS」本文 | Obsidian Preview + フローティングオーバーレイ（**v0.49.1 ホットフィックス**で rAF 化） |
| F030 | チャットメッセージの DOM post-process | Obsidian 標準 MarkdownRenderer |
| F031 | F028 再生中の ⏸/⏭ 押下 | PlaybackController（音声本体制御） |
| F032 | テキスト選択時のフローティングポップアップ | `selection.popupPosition` 既定 `top-right` |
| F033 | LLM 原稿整形経路 | `tts.llmRewriteConcurrency` 1〜8・並列生成・ストリーミング読上げ |
| F038 | MD「Add to TTS」対象 | `<style>`/`<script>` タグ除去 |
| F039 / F040 | TTS 読上げ経路・自動/手動 | `LlmClient` 抽象化 + `dispatch.ts` で 5 プロバイダ直接呼び出し |
| F041 | `.ovpn` ファイル + auth-user-pass | OpenVPN CLI（stderr + stdout 監視）+ `reapOrphanOpenVpn()` で孤児プロセス回収 |
| F042 | 設定 UI | 🌐ネットワークタブ新設（プロキシ設定を一般タブから移動）+ OpenVPN 接続セクション |
| F043 | YOLO トグル横 | ワンショット方式・状態バッジ 4 値・複数 Claudian タブ自動追随（MutationObserver） |
| F044 | ネットワークタブ「サーバ上書き（任意）」 | openvpn CLI の `--remote` 引数による DDNS 上書き |
| F045 | openvpn ログ + 経路表 | 正しいゲートウェイとの照合・`On-link` 行除外 |
| F046 | 設定 → 🌐ネットワーク「🧹 Remove stale routes」 | 管理者判定 + VPN ホワイトリスト + route delete |
| F047 | OpenVPN 切断時 | `setTimeout(3000)` で `cleanupAfterDisconnect()` をスケジュール |
| F048 | LLM 残量検知（Zhipu） | `open.bigmodel.cn/api/monitor/usage/quota/limit`（httpGet + 生 Bearer キー） |
| F049 | `general.outputsMirrorEnabled` | NTFS ジャンクション（`Documents/ObsidainOutputs`）+ `hideDotFolders` |
| F050 | TTS 自動読上げ経路 | `tts.chatReadHighlight.enabled` 既定 ON・最後の `.claudian-message-assistant` にクラス付与・世代トークン |
| F051 | MD ファイル表示中 | `MarkdownView.addAction('volume-2', ...)` で ✏️ の左に描画・`layout-change` で `[data-cb-add-tts]` マーカー付き冪等追加 |
