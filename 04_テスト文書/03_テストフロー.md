## 🔄 主テストフロー


<div style="max-width:1000px">

```mermaid
flowchart TB
    Start([テスト開始]) --> Plan[テスト計画]
    Plan --> Design[テストケース設計]
    Design --> Execute[テスト実行]
    Execute --> Record[結果記録]
    Record --> Bug{Bug 発見?}
    
    Bug -->|はい| Track[Bug 追跡]
    Track --> Fix[Bug 修正]
    Fix --> ReTest[回帰テスト]
    ReTest --> Execute
    
    Bug -->|いいえ| Analyze[結果分析]
    Analyze --> Report[レポート作成]
    Report --> Accept{受け入れ合格?}
    
    Accept -->|はい| End([テスト完了])
    Accept -->|いいえ| Execute
    
    style Start fill:#90EE90
    style End fill:#FFB6C1
    style Bug fill:#FFD700
    style Accept fill:#FFD700
```


</div>

## 🔍 詳細サブフロー

### フロー 1:単体テスト


<div style="max-width:1000px">

```mermaid
flowchart LR
    A[テスト作成] --> B[ローカル実行]
    B --> C{合格?}
    C -->|はい| D[コード提出]
    C -->|いいえ| E[コード修正]
    E --> B
    D --> F[CI 自動実行]
    F --> G{合格?}
    G -->|はい| H[マージ]
    G -->|いいえ| I[開発者へ通知]
    I --> E
```


</div>

### フロー 2:回帰テスト


<div style="max-width:1000px">

```mermaid
flowchart TB
    Start([新機能マージ]) --> Identify[影響範囲の特定]
    Identify --> Select[回帰テストケースの選択]
    Select --> Run[回帰テスト実行]
    Run --> Verify{すべて合格?}
    
    Verify -->|はい| Pass([回帰合格])
    Verify -->|いいえ| Bug[Bug レポート]
    Bug --> Fix[修正]
    Fix --> Run
```


</div>

### フロー 3:Bug 提出フロー


<div style="max-width:1000px">

```mermaid
flowchart TB
    Found[Bug 発見] --> Reproduce{再現可能?}
    
    Reproduce -->|はい| Document[Bug レポート作成]
    Reproduce -->|いいえ| Investigate[詳細調査]
    Investigate --> Document
    
    Document --> Assign[責任者割り当て]
    Assign --> Fix[修正]
    Fix --> Verify[検証]
    Verify --> Close{合格?}
    
    Close -->|はい| Done([Bug クローズ])
    Close -->|いいえ| Reopen[再オープン]
    Reopen --> Fix
```


</div>

### フロー 4: Forced reflow 嵐の緊急対応（v0.49.1 ホットフィックス）


<div style="max-width:1000px">

```mermaid
flowchart TB
    Start([v0.49.0 リリース]) --> User[ユーザー読上げ開始]
    User --> Reflow{Forced reflow<br/>114ms ピーク発生?}
    
    Reflow -->|はい| Diag[DevTools Performance タブで犯人特定]
    Diag --> Locate[scrollIntoView{behavior:'smooth'}<br/>と getBoundingClientRect を検出]
    Locate --> Patch[requestAnimationFrame 内で<br/>behavior:'auto' 化]
    Patch --> Hotfix[v0.49.1 hotfix リリース<br/>ピーク 53ms に削減]
    Hotfix --> Verify[Performance タブで<br/>53ms 以下を確認]
    
    Reflow -->|いいえ| Pass([継続監視])
    Verify --> Pass
```

### フロー 6: チャット読上げハイライト + MD 画面ボタン（F050/F051）


<div style="max-width:1000px">

```mermaid
flowchart TB
    Start([ユーザー読上げ開始]) --> Path{経路は?}
    
    Path -->|自動（ストリーミング完了）| Auto[auto-read.ts の speak ラップ]
    Path -->|MD Add to TTS ボタン| Md[setupMdViewButton]
    
    Auto --> Token[世代トークン latestToken++]
    Md --> Token
    
    Token --> Activate[chat-read-highlight.activate<br/>クラス付与 + 背景色]
    Activate --> Scroll[rAF 内で<br/>scrollIntoView behavior:'auto']
    Scroll --> Highlight[アンバー背景 + 黄色左罫線]
    
    Highlight --> Loop{読上げ継続中?}
    Loop -->|はい| Wait[次のチャンク]
    Wait --> Loop
    Loop -->|いいえ| Deactivate[chat-read-highlight.deactivate]
    Deactivate --> End([完了])
    
    style Start fill:#90EE90
    style Highlight fill:#FFD700
    style Scroll fill:#FFD700
```
