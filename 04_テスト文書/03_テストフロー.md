## 🔄 主テストフロー

```mermaid
flowchart TB
    Start([テスト開始]) --> Plan[テスト計画]
    Plan --> Design[テストケース設計]
    Design --> Execute[テスト実行]
    Execute --> Record[結果記録]
    Record --> Bug{Bug 発見?}
    
    Bug -->|はい| Track[Bug 追跡]
    Track --> Fix[Bug 修正]
    Fix --> ReTest[回帰テスト]
    ReTest --> Execute
    
    Bug -->|いいえ| Analyze[結果分析]
    Analyze --> Report[レポート作成]
    Report --> Accept{受け入れ合格?}
    
    Accept -->|はい| End([テスト完了])
    Accept -->|いいえ| Execute
    
    style Start fill:#90EE90
    style End fill:#FFB6C1
    style Bug fill:#FFD700
    style Accept fill:#FFD700
```

## 🔍 詳細サブフロー

### フロー 1:単体テスト

```mermaid
flowchart LR
    A[テスト作成] --> B[ローカル実行]
    B --> C{合格?}
    C -->|はい| D[コード提出]
    C -->|いいえ| E[コード修正]
    E --> B
    D --> F[CI 自動実行]
    F --> G{合格?}
    G -->|はい| H[マージ]
    G -->|いいえ| I[開発者へ通知]
    I --> E
```

### フロー 2:回帰テスト

```mermaid
flowchart TB
    Start([新機能マージ]) --> Identify[影響範囲の特定]
    Identify --> Select[回帰テストケースの選択]
    Select --> Run[回帰テスト実行]
    Run --> Verify{すべて合格?}
    
    Verify -->|はい| Pass([回帰合格])
    Verify -->|いいえ| Bug[Bug レポート]
    Bug --> Fix[修正]
    Fix --> Run
```

### フロー 3:Bug 提出フロー

```mermaid
flowchart TB
    Found[Bug 発見] --> Reproduce{再現可能?}
    
    Reproduce -->|はい| Document[Bug レポート作成]
    Reproduce -->|いいえ| Investigate[詳細調査]
    Investigate --> Document
    
    Document --> Assign[責任者割り当て]
    Assign --> Fix[修正]
    Fix --> Verify[検証]
    Verify --> Close{合格?}
    
    Close -->|はい| Done([Bug クローズ])
    Close -->|いいえ| Reopen[再オープン]
    Reopen --> Fix
```
