## 🧰 v0.49.1 テストツール用語

| 用語 | 英語 | 略称 | 定義 |
|------|------|------|------|
| **vitest** | Vitest | — | **TypeScript 単体テストランナー**。`tests/` は `src/` とミラー構成、obsidian モジュールはスタブ化（**131 ファイル・1362 件**） |
| **jsdom** | jsdom | — | **vitest 環境**。ブラウザ DOM を Node.js で再現（`@vitest-environment jsdom`） |
| **mockFetchOnce** | mockFetchOnce | — | fetch モックヘルパー（F048 Zhipu 純 TS 化テストで使用） |
| **`vi.fn`** | vi.fn | — | vitest の関数スパイ（`.mockResolvedValueOnce` 等） |
| **`vi.mock`** | vi.mock | — | vitest のモジュールモック |
| **`vi.stubGlobal`** | vi.stubGlobal | — | グローバル（`requestAnimationFrame` 等）のスタブ化（F050 テストで使用） |
| **`unstubAllGlobals`** | unstubAllGlobals | — | グローバルスタブの解除（afterEach で呼ぶ） |
| **longtask observer** | longtask observer | — | **`PerformanceObserver({ entryTypes: ['longtask'] })`** で 50ms 超の処理を記録（Forced reflow 検証） |
| **Forced reflow** | Forced Reflow | — | JavaScript がレイアウトスラスタを強制する状態。**v0.49.1 ホットフィックスで 114ms → 53ms に削減** |
| **MutationObserver** | MutationObserver | — | DOM 変更監視 API。F029/F051 の layout-change フックや Claudian 画面 VPN トグルのタブ追随で使用 |
| **ScrollIntoView rAF** | ScrollIntoView rAF | — | `requestAnimationFrame` 内で `scrollIntoView({behavior:'auto'})` を実行する手法（**v0.49.1 ホットフィックスの核心**） |
| **NTFS ジャンクション** | NTFS Junction | — | Windows のリパースポイント機能。F049 Outputs ミラーリングで使用 |
| **TAP アダプタ** | TAP Adapter | — | OpenVPN が使用する仮想ネットワークアダプタ。Windows では `tap-windows6`。孤児プロセス占有時に新規接続が失敗（F041） |
| **`route print`** | route print | — | Windows のルーティングテーブル表示コマンド。VPN 経路検証と残骸検知で使用（F045） |
| **Bearer キー** | Bearer Key | — | API キーを JWT 等に変換せず `Authorization: Bearer <key>` で送る方式。**F048 Zhipu 純 TS 化で採用** |
| **raw HTTP** | raw HTTP | — | SDK を使わず生の fetch / httpGet で API を呼ぶこと（**F048 で zai-sdk 依存を排除**） |
| **`MarkdownView.addAction`** | MarkdownView.addAction | — | Obsidian 公開 API。MD 画面ビューヘッダにアイコンを追加（**F051 で使用**） |
| **`lstat`** | lstat | — | シンボリックリンク判定用のファイル状態取得。**F049 でジャンクション vs 実フォルダ判定に使用** |
| **`chmod 600`** | chmod 600 | — | ファイル所有者のみ読み書き可能にする権限設定。**F041 OpenVPN auth-user-pass 一時ファイルで使用** |
