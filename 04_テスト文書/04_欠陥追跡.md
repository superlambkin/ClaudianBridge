## 🐛 Bug ライフサイクル

```mermaid
stateDiagram-v2
    [*] --> New : テスターによる提出
    New --> Confirmed : 有効性確認
    New --> Rejected : 誤検出/Wontfix
    Rejected --> [*]
    
    Confirmed --> Assigned : 開発者へ割り当て
    Confirmed --> Deferred : 延期
    
    Assigned --> InProgress : 修正開始
    InProgress --> Fixed : 修正完了
    InProgress --> Wontfix : 修正しない
    
    Fixed --> Verified : 検証合格
    Fixed --> Reopened : 検証不合格
    
    Reopened --> InProgress : 修正継続
    Verified --> Closed : クローズ
    Closed --> [*]
    
    Deferred --> Confirmed : 再アクティブ化
    Wontfix --> [*]
```

## 📋 Bug レベル

| レベル | 名称 | 応答時間 | 修正時間 | 説明 |
|:----:|------|:--------:|:--------:|------|
| **P0** | 致命 | 1h | 24h | システム崩壊、データ消失 |
| **P1** | 重大 | 4h | 3d | コア機能使用不可 |
| **P2** | 一般 | 1d | 1w | 機能制限あり、回避策あり |
| **P3** | 軽微 | 1w | 2w | UI/文言/最適化 |
