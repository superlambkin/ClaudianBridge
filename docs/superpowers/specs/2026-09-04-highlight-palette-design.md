## 1. 背景・目的

v0.35.0 で追加したハイライト色プリセット（8 色）に濃い色がなく、また自由入力欄は
一般人に使いにくい。プリセットを 16 色へ拡張し、テキスト入力をカラースウォッチ
（色チップ）グリッド＋カスタムピッカーに置き換える。

## 2. 要件

| # | 要件 |
|:-:|------|
| R1 | プリセット 16 色（通常 8 + 濃い 8） |
| R2 | スウォッチグリッド（8 列 × 2 行）クリックで即反映・選択中は枠強調 |
| R3 | テキスト入力欄を廃止し、代わりにカスタムチップ（`input[type=color]`）を提供 |
| R4 | 設定キー `mdReadHighlight.highlightColor` 不変（後方互換） |
| R5 | i18n ja/zh/en に濃い色名 8 個＋カスタムラベル追加 |

## 3. カラーパレット

| 系統 | 通常 | 濃い |
|------|------|------|
| アンバー | `#ffb300` | `#b26a00` |
| 黄 | `#ffd54f` | `#f9a825` |
| 緑 | `#a5d6a7` | `#43a047` |
| 青系 | `#81d4fa` | `#1e88e5` |
| 桃/赤 | `#f48fb1` | `#e53935` |
| 橙 | `#ffab91` | `#f4511e` |
| 紫 | `#ce93d8` | `#8e24aa` |
| グレー | `#cfd8dc` | `#607d8b` |

透明度は既存 `applyHighlightColor` の 35% 半透明化に委ねる。

## 4. UI 構成

- 既存プルダウン（v0.35.0）をスウォッチグリッドに置換（プルダウン廃止・重複回避）
- スウォッチ: 24×24px 角丸チップ。`aria-label` に色名。選択中は `border: 2px solid var(--text-accent)`
- カスタムチップ: `input[type=color]` をグリッド末尾に配置。変更で即反映
- 反映時は `applyHighlightColor(color)` を呼びプレビューへ即時適用

## 5. テスト（TDD）

1. スウォッチ数 = 16・クリックで設定反映＋applyHighlightColor 呼び出し
2. 選択中スウォッチに強調クラス
3. カスタム変更で反映
4. 既存の色設定キー後方互換（normalize テスト維持）
