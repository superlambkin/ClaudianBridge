# MD 読み上げ聴き手プロファイル（F-032）

> 📂 パス：docs/superpowers/specs/2026-09-05-md-read-profile-design.md
> 📍 源码：D:\AI-Agent\ClaudianBridge\src\features\tts\
> 🏷️ バージョン：v1.0（2026-09-05 設計）

---

## 1. 背景・目的

Add to TTS で読み上げる内容を、**聴き手の属性・シーン**に応じて口調・専門用語の言い換え・トーン（警告音など）を適用する。これにより職場メモ・顧客レビュー・家族共有・学生教材・上司報告・DR といった異なる文脈で同じ MD を「読み上げ方だけ」切り替えられる。

## 2. 要件

| # | 要件 | 決定 |
|:-:|------|------|
| R1 | プロファイル種別 | 7 種（原文 / 職場 / 顧客 / 家族 / 教室 / 上司 / DR） |
| R2 | 設定キー | `tts.mdReadProfile: string`（既定 `'original'`） |
| R3 | 用語辞書 | `tts.termsDict: string`（Vault 内 MD パス・既定 `''`） |
| R4 | 設定 UI | テキスト読み上げタブにプルダウン追加 |
| R5 | 変換処理 | プレーン MD 抽出 → 既存フィルタ → **新規プロファイル変換** → チャンク分割 |
| R6 | DR 警告音 | Web Audio API で生成した短音ビープを該当箇所に挿入 |
| R7 | 上司プロファイル | `🎯 結論` 見出しを先頭に並び替え → 他は元の順 |
| R8 | キャッシュ | しない（毎回変換・mtime 監視なし） |
| R9 | 用語辞書デフォルト | `00_Vault管理/Tech_用語対照表.md`（存在しなければ無視） |
| R10 | i18n | ja/zh/en すべてにプロファイル表示名を翻訳 |

## 3. 変換アーキテクチャ

```
input MD → extractMdText → filterSpeechText
   ↓
[新] applyProfileTransform(text, profile, termsMap)
   ↓
chunkTextNatural → speakChunks
```

| コンポーネント | 責務 |
|------|------|
| `profile.ts`（新） | プロファイル種別 enum・`applyProfileTransform(text, profile, termsMap)` 実装 |
| `terms-dict.ts`（新） | 指定パスの MD を読み「用語 → やさしい表現」テーブルを返す |
| `audio-beep.ts`（新） | DR 用 Web Audio 短音生成（コードフェンス・チェックリスト警告音） |
| `setting-ui` | プルダウン・用語辞書パス入力 |
| `speak.ts` 拡張 | 変換→ビープ挿入→speakChunks へ |

## 4. プロファイル別動作

| プロファイル | 略語変換 | 口調 | 数字 | 警告音 | 並び順 |
|------|---|---|---|---|---|
| original | – | – | – | – | 元 |
| workplace | ✓（1 文字ずつ） | そのまま | 数字 | – | 元 |
| customer | ✓（一般語置換） | ですます | 数字 | – | 元 |
| family | ✓（全て口語） | やさしい | 漢数字 | – | 元 |
| classroom | ✓（解説付記） | ていねい | 数字 | – | 元 |
| boss | – | 結論→根拠 | 漢数字 | – | 🎯 結論 を先頭 |
| dr | – | 校正 | 数字 | ✓ 誤字疑い | 元 |

### 4.1 workplace（職場技術）

- 略語を 1 文字ずつカタカナ読み（`API` → `エー ピー アイ`）
- 略語辞書（スペース区切り 50 語程度：API / URL / HTTP / JSON / CLI 等）

### 4.2 customer（顧客）

- 略語を「アプリケーションとやりとりする仕組み」風に展開
- コードフェンスは「コードブロック省略」に置換
- テーブル・タスクリストを省略

### 4.3 family（家族）

- 略語・専門用語を全て口語化
- 数字を漢数字で読み（`3` → `さん`、`100` → `ひゃく`）
- コード・テーブル・タスクは省略

### 4.4 classroom（教室）

- 専門用語の直後に「〜とは〇〇」を自動付記（用語辞書を使用）
- コードは「コード例省略」、図は「ここに図があります」
- 丁寧体（ですます調）

### 4.5 boss（上司）

- チャンク配列を反転： 🎯 結論 → 🎯 実装方針 → ✅完了 の順に並び替え
- 数字を漢数字で読み
- タスクリスト・コードは省略

### 4.6 dr（ドキュメント査読）

- 誤字疑い箇所に Web Audio 短音（880Hz・80ms）を挿入
- チェックリスト項目を `⚠️ 項目1 ... ⚠️ 項目2 ...` のように強調
- 修正提案を `TODO: ...` で読み上げ

## 5. UI

設定画面「テキスト読み上げ」タブの「ハイライト色」の上に追加：

| 項目 | UI 部品 | 動作 |
|------|---------|------|
| 聴き手プロファイル | プルダウン（7 種） | 選択→即保存 |
| 用語辞書（任意） | テキスト入力 | Vault パス・空でも可 |

## 6. テスト

| テスト | 内容 |
|------|------|
| workplace | `API` → `エー ピー アイ` |
| customer | コードフェンスが「コードブロック省略」に置換 |
| family | 数字が漢数字に変換 |
| classroom | 用語辞書の用語直後に解説付与 |
| boss | `🎯 結論` がチャンク配列の先頭 |
| dr | 警告音が音再生 API を呼ぶ・誤字疑い箇所をビープで挟む |
| original | 変換なし（既存挙動） |
| terms-dict | 空ファイル時・存在しないパス時の no-op |

## 7. 互換性

- 設定キー `tts.mdReadProfile` が未設定の場合 `'original'` として動作（既存ユーザーは無変更）
- `termsDict` が空・ファイルなし → 単に置換スキップ
- Web Audio API 未対応の環境ではビープをスキップ（ログのみ）
