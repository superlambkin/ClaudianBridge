## 📏 TypeScript 基本方針

| ルール | 規約 |
|------|------|
| **型チェック** | strict mode（`noImplicitAny: true` 含む） |
| **target** | ES2022 |
| **ビルド** | esbuild で CJS 単一バンドル（`main.js`） |
| **テスト** | vitest でユニットテスト（**TDD** で失敗→実装→PASS） |
| **import** | 相対 import を使用（絶対 import 禁止） |
| **docstring** | 公開関数・クラスには JSDoc |

## 📝 Commit Message 規約（v1.2.0 追加）

Claudian Bridge の commit message は以下の規約に従う。

### プレフィックス

| プレフィックス | 用途 | 例 |
|--------------|------|-----|
| `feat(F番号):` | 新機能 | `feat(F024): TTS エンジン変更 ...` |
| `fix(F番号):` | バグ修正 | `fix(F019): バックアップダイアログが開かない問題を修正` |
| `refactor:` | リファクタリング | `refactor: rename claudian-bridge → ClaudianBridge ...` |
| `chore:` | ビルド・依存関係・バージョンバンプ | `chore: v0.27.0 バージョンバンプ` |
| `docs(POC_017):` | ドキュメント更新 | `docs(POC_017): README.md を v0.27.1 に更新` |
| `test:` | テスト追加・修正 | `test: pickLang の言語モード別テスト追加` |

### ルール

1. **F-番号必須**: `feat` / `fix` コミットは対応する F-番号を必ず含める
2. **日本語 OK**: 説明は日本語で OK（AI 整形の柔軟性を優先）
3. **Co-Authored-By 必須**: 末尾に `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` を付与
4. **release commit**: `chore(release): bump version to X.Y.Z` で統一
5. **docs commit**: `docs(POC_017): <対象> を <変更内容>` 形式

### 例

```bash
git commit -m "feat(F024): TTS エンジン変更（edge_tts 同梱 + cloud proxy + 言語モード）

- edge_tts v7.2.8 を py/edge_tts/ に同梱
- クラウド HTTPS プロキシ対応
- Add to TTS / AI 自動読上げ で独立した言語モード

Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>"
```
