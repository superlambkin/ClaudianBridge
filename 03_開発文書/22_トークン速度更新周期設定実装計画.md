**Goal:** トークン速度表示の更新周期（intervalMs）を 100/250/500/1000/2000 ms から選択できるようにし、即時反映する。

**Architecture:** v0.31.0 で確立した「設定 → store.save → rescan 再注入」パターンを踏襲。新周期も `CounterOptions.intervalMs` として渡し、counter 要素の `data-interval` 属性を経由して設定変更時に再注入する。Task 4 の偽スパイク修正は周期に依存しないロジックのため影響なし。

**Tech Stack:** TypeScript / Obsidian Plugin API / vitest (jsdom)

## Global Constraints

- リポジトリ: `D:/AI-Agent/ClaudianBridge`
- 既定値: **250 ms**（v0.31.0 の 500 から変更・既存 JSON は normalize で 250 補完）
- プリセット: **100 / 250 / 500 / 1000 / 2000 ms**（ドロップダウン）
- i18n: **ja / en / zh**（`SUPPORTED_LOCALES`）
- 反映: **即時反映**（破棄・再注入）

          avg: b('tokenRateShowAvg', true),
          max: b('tokenRateShowMax', true),
        },
