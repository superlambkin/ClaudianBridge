## 🚀 セットアップ手順

```bash
# 1. 依存関係のインストール
cd "D:/AI-Agent/ClaudianBridge" && npm install

# 2. 型チェック（tsc -noEmit）
npm run typecheck

# 3. テスト実行（vitest）
npm test

# 4. ビルド（esbuild production → main.js）
npm run build

# 5. デプロイ（Obsidian プラグインフォルダへコピー）
npm run deploy
```

> 💡 `npm run deploy` は `main.js` / `manifest.json` / `styles.css` を
> `.obsidian/plugins/claudian-bridge/` へコピーします。
> 反映後は Obsidian の「Claudian Bridge」プラグインを再読み込みしてください。

---

## 🔧 ビルド設定の要点

| ファイル | 役割 |
|------|------|
| `package.json` | スクリプト（build / dev / test / deploy / typecheck） |
| `tsconfig.json` | TS strict mode・ES2022・inlineSourceMap |
| `esbuild.config.mjs` | entry `src/main.ts` → `main.js`（CJS・minify） |
| `vitest.config.ts` | `tests/**/*.test.ts` を Node 環境で実行 |
| `scripts/deploy.mjs` | 成果物を `.obsidian/plugins/claudian-bridge/` へコピー |
| `src/manifest.json` | プラグイン定義（id: `claudian-bridge`, isDesktopOnly: true） |
