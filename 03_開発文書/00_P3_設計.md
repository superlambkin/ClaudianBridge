# 🏗️ P3 設計：Office 変換統合（F004）

## 🎯 結論（一行）

旧プラグイン `vault-office-bridge` の Office/PDF/HTML/CSV → Markdown 変換機能（Convert to Markdown / Convert & Split / 複数選択変換 / 進捗モーダル）を Claudian Bridge の `src/features/office/` にモジュール化して移植し、設定スキーマ・データ移行・設定タブ・i18n を統合する。

## 📌 設計方針

- **完全互換**: Convert + Split + 複数選択変換を全て移植（ユーザー承認済み）
- **P2 アーキテクチャ踏襲**: ConfigStore（同期）+ i18n + TDD（vitest）
- **外部スクリプト依存維持**: `00_Vault管理/_設定ファイル/_scripts/` の `_run_markitdown.py` / `split_*.py` を参照（`__dirname` 不使用・`app.vault.adapter.basePath` から解決）
- **CSS 接頭辞**: 旧 `vob-` → 新 `cb-` に統一

---

## ① 設定スキーマ（`src/core/settings.ts`）

`office: Record<string, never>` を実スキーマに置換：

```typescript
office: {
  enabled: boolean;                    // 機能ON/OFF（新設）
  pythonPath: string;                  // 旧: pythonPath
  markitdownArgs: string;              // 旧: markitdownArgs（予約・UI非表示）
  enabledExtensions: string[];         // 旧: enabledExtensions
  conflictPolicy: 'overwrite' | 'skip' | 'timestamp';  // 旧: conflictPolicy
  frontmatterTemplate: string;         // 旧: frontmatterTemplate
  logLevel: 'debug' | 'info' | 'warn' | 'error';       // 旧: logLevel（予約・UI非表示）
  showProgressModal: boolean;          // 旧: showProgressModal
  outputDirOverride: string;           // 旧: outputDirOverride
}
```

**デフォルト値**（旧 `DEFAULT_SETTINGS` と一致）:

| フィールド | デフォルト |
|------|------|
| enabled | `true` |
| pythonPath | Windows: `py` / その他: `python3` |
| markitdownArgs | `""` |
| enabledExtensions | `["docx","xlsx","pptx","pdf","html","htm","csv"]` |
| conflictPolicy | `"overwrite"` |
| frontmatterTemplate | 旧デフォルト（title/sourcePath/date/ext/sizeBytes/sha256 対応） |
| logLevel | `"info"` |
| showProgressModal | `true` |
| outputDirOverride | `""` |

**normalize**: 欠落キーをデフォルトで埋める（P2 と同型）
**validate**: `enabled` boolean / `enabledExtensions` string[] / `conflictPolicy` enum / `pythonPath` string 等

## ② データ移行（`src/legacy/`）

| ファイル | 変更 |
|------|------|
| `read-legacy.ts` | `readLegacyDataJson(pluginsDir, id)` を `pluginsDir/_disabled__<id>/data.json` にもフォールバック |
| `convert-vob.ts`（新規） | `convertFromVaultOfficeBridge(raw): Partial<ClaudianBridgeSettings> \| null` |
| `migration.ts` | vault-office-bridge 変換 + `data.json.bak.json` バックアップ + `migratedFrom.vaultOfficeBridge = true` |

> ⚠️ P2 で旧フォルダは `_disabled__vault-office-bridge` にリネーム済み。
> 移行は **`_disabled__` プレフィックス付きフォルダ** から読み取る。

**変換マッピング**（`vault-office-bridge/data.json` → `office`）:

```typescript
office: {
  enabled: true,
  pythonPath: raw.pythonPath,            // 型・空値チェック付き
  markitdownArgs: raw.markitdownArgs,
  enabledExtensions: Array.isArray(...) ? ... : DEFAULT,
  conflictPolicy: ['overwrite','skip','timestamp'].includes(...) ? ... : 'overwrite',
  frontmatterTemplate: typeof raw.frontmatterTemplate === 'string' ? ... : DEFAULT,
  logLevel: ['debug','info','warn','error'].includes(...) ? ... : 'info',
  showProgressModal: typeof raw.showProgressModal === 'boolean' ? ... : true,
  outputDirOverride: typeof raw.outputDirOverride === 'string' ? ... : '',
}
```

## ③ 機能モジュール（`src/features/office/`）

```
src/features/office/
├── markitdown.ts       # spawnPython / resolvePython / run（Windows shell 対応・UTF-8）
├── converter.ts        # convertItem / convertMany（変換パイプライン）
├── frontmatter.ts      # FrontmatterApplier.expand（テンプレート展開）
├── splitter.ts         # SplitterRunner.split（拡張子別 split_*.py）
├── summary.ts          # ConversionSummary.toMarkdown（複数変換サマリー）
├── progress-modal.ts   # ProgressModal（進捗UI・cb- クラス）
└── menu.ts             # registerFileMenu + registerMultiSelect
```

### 移植する重要ロジック

| モジュール | 移植ポイント |
|------|------|
| `markitdown.ts` | Windows の `shell:true` + 手動クォート（DEP0190 回避）、`PYTHONIOENCODING=utf-8` / `PYTHONUTF8=1`、`resolvePython` のフォールバックチェーン（絶対パス→裸名→既知インストール先）、JSON エンベロープ unwrap |
| `converter.ts` | ステージ進行（Reading source → Invoking markitdown → Writing main .md → Splitting）、sha256 前付与、`conflictPolicy` 別出力名、`outputDirOverride` 解決 |
| `splitter.ts` | 拡張子→スクリプト対応表（docx/xlsx/pptx/pdf/html/htm/csv） |
| `frontmatter.ts` | `{{placeholder}}` 正規表現展開・未知キーはそのまま |
| `progress-modal.ts` | ステージ表示・進捗バー・ログ textarea・ボタン制御（Copy/Open/Retry/Settings/Split/Close） |
