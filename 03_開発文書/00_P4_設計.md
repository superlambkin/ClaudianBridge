# 🏗️ P4 設計：拡張子フィルタ統合（F005）

## 🎯 結論（一行）

旧プラグイン `extension-whitelist` の拡張子フィルタ機能（CSS注入による左サイドバーのファイル一覧絞り込み + プリセット5種 + タグUI）を Claudian Bridge の `src/features/whitelist/` に純ロジック（CSS生成 + プリセットデータ）と Obsidian DOM 注入に分離して移植し、設定スキーマ・データ移行・設定タブ・i18n を統合する。

## 📌 設計方針

- **完全互換**: 旧プラグインの設定タブ UI（有効化 / 拡張子追加・削除 / プリセット5種 / フォルダ常時表示 / リセット）を全て移植（ユーザー承認済み）
- **2層分離**: 純ロジック（CSS生成・プリセットデータ）は TDD、DOM 注入は薄いラッパー
- **CSS 戦略**: 旧プラグインの `:has()` 方式を **そのまま** 採用（後方互換・シンプル）
- **CSS クラス接頭辞**: 全て `cb-whitelist-*`（旧 `ext-whitelist-*` は使わない）

---

## ① 設定スキーマ（`src/core/settings.ts`）

`whitelist: Record<string, never>` を実スキーマに置換：

```typescript
whitelist: {
  enabled: boolean;
  extensions: string[];
  alwaysShowFolders: boolean;
}
```

**デフォルト値**（旧 `DEFAULT_SETTINGS` と一致）:

| フィールド | デフォルト |
|------|------|
| enabled | `true` |
| extensions | `["md","canvas","pdf","png","doc","docx","xls","xlsx","ppt","pptx"]` |
| alwaysShowFolders | `true` |

**normalize**: 欠落キーをデフォルトで埋める。`extensions` 要素は `trim + lowercase + 先頭ドット除去 + 空文字除去` で正規化。
**validate**: `enabled` boolean / `alwaysShowFolders` boolean / `extensions` string[]

## ② データ移行（`src/legacy/`）

| ファイル | 変更 |
|------|------|
| `convert-ew.ts`（新規） | `convertFromExtensionWhitelist(raw): Partial<ClaudianBridgeSettings> \| null` |
| `migration.ts` 更新 | extension-whitelist 変換 + `.bak.json` バックアップ + `migratedFrom.extensionWhitelist = true` |

> 旧フォルダは `_disabled__extension-whitelist` にリネーム済み。Task 4 の `legacyDataJsonPath` が自動的にフォールバック読み取り。

**変換マッピング**（`extension-whitelist/data.json` → `whitelist`）:

```typescript
whitelist: {
  enabled: typeof raw.enabled === 'boolean' ? raw.enabled : true,
  extensions: Array.isArray(raw.extensions)
    ? raw.extensions.filter((e) => typeof e === 'string').map((e) => e.trim().toLowerCase().replace(/^\./, '')).filter(Boolean)
    : [...DEFAULT_WHITELIST_SETTINGS.extensions],
  alwaysShowFolders: typeof raw.alwaysShowFolders === 'boolean' ? raw.alwaysShowFolders : true,
}
```

## ③ 純ロジック + プリセット

```
src/features/whitelist/
├── css-builder.ts       # buildWhitelistCss(extensions, alwaysShowFolders): string | null
└── presets.ts           # WHITELIST_PRESETS: ReadonlyArray<WhitelistPreset>
```

### `buildWhitelistCss` の挙動

- `extensions.length === 0` → `null`（フィルター無効化）
- そうでない場合:
  ```css
  /* ── Claudian Bridge Whitelist ── */
  .nav-files-container .nav-file:not(:has(
    > .nav-file-title:is(
      [data-path$=".md" i],
      [data-path$=".pdf" i],
      ...
    )
  )) {
    display: none !important;
  }
  /* folders always visible */
  .nav-folder { display: flex !important; }
  ```
- `alwaysShowFolders=false` → 末尾の `.nav-folder` 行は省略

### プリセット（`WHITELIST_PRESETS`、旧と完全一致）

| name | extensions |
|------|------|
| 📄 Obsidian標準 | `["md","canvas"]` |
| 📊 Office | `["doc","docx","xls","xlsx","ppt","pptx"]` |
| 🖼️ 画像 | `["png","jpg","jpeg","gif","svg","webp","bmp"]` |
| 💻 コード | `["js","ts","py","json","yaml","xml","css","html","sh"]` |
| 📦 ALL | `["*"]`（特殊: 適用時に `extensions` を空配列にする） |

### インターフェース

```typescript
export interface WhitelistPreset {
  name: string;
  extensions: string[];
  desc: string;
}
export const WHITELIST_PRESETS: ReadonlyArray<WhitelistPreset>;
export function buildWhitelistCss(extensions: string[], alwaysShowFolders: boolean): string | null;
```

## ④ DOM 注入（`src/features/whitelist/injector.ts`）

```typescript
export function installWhitelistCss(css: string): void
export function removeWhitelistCss(): void
```

- `<style id="cb-whitelist-css">` タグを `document.head` に追加
- 既存タグがあれば差し替え
- プラグイン unload / `whitelist.enabled=false` / `extensions.length=0` で remove

## ⑤ 設定タブ（`src/settings/SettingTabWhitelist.ts`）+ i18n

プレースホルダーを本実装に置換。表示項目：

| 項目 | UI | i18n キー |
|------|-----|-----------|
| enabled | toggle | `whitelistEnabled` |
| 拡張子追加 | text + ボタン + Enter | `whitelistAddExtension`, `whitelistAddExtensionDesc`, `whitelistAddExtensionPlaceholder`, `whitelistAddExtensionButton` |
| 拡張子タグ | 各 ✕ ボタン削除 | `whitelistExtensionsHeading`, `whitelistExtensionsDesc` |
| プリセット | グリッドカード5枚 | `whitelistPresetsHeading`, `whitelistPresetsDesc`, `whitelistApplyButton` |
| alwaysShowFolders | toggle | `whitelistAlwaysShowFolders`, `whitelistAlwaysShowFoldersDesc` |
| リセット | ボタン | `whitelistReset`, `whitelistResetDesc`, `whitelistResetButton`, `whitelistResetConfirm` |

`src/core/i18n.ts` に whitelist ラベル（ja/zh/en）を追加。`comingSoon` の Whitelist タブ分は削除。

### UI パターン（タグ・プリセット）

旧プラグインのタグUI/プリセットUIを **完全移植**（CSS クラス `cb-whitelist-*` に変更）。

```typescript
// タグ
const tag = container.createEl('span', { cls: 'cb-whitelist-tag' });
tag.createEl('span', { text: `.${ext}` });
const removeBtn = tag.createEl('span', { cls: 'cb-whitelist-tag-remove', text: '✕' });
removeBtn.addEventListener('click', async () => { /* remove */ });

// プリセットカード
const card = container.createDiv('cb-whitelist-preset-card');
card.createEl('div', { text: preset.name });
const btn = card.createEl('button', { text: s.whitelistApplyButton });
btn.addEventListener('click', async () => { /* apply */ });
```

## ⑥ main.ts オーケストレーション

- `SettingTabWhitelist` プレースホルダー → 本実装に差し替え
- `onload` で `installWhitelistCss(buildWhitelistCss(cfg.whitelist.extensions, cfg.whitelist.alwaysShowFolders))`（cfg.enabled=false なら install しない）
- ConfigStore.watch で whitelist 変更時に CSS 再注入
- `onunload` で `removeWhitelistCss()`
