## 🔧 TTS 読み上げ（3 エンジン）

> Claudian チャットのテキストを **edge-TTS / WebSpeech / Plachta Cloud VITS** の 3 エンジンで音声読み上げします（v0.1.0〜）。

### 入口

- ClaudianChat の入力ツールバーの **🔊 / 🔇 ボタン**（ミュート切替・再生中は点滅）
- 結果欄の各テキストブロックの **読上げボタン**（v0.14.0）
- ファイルエクスプローラの `.md` 右クリック → **「Add to TTS」**（v0.17.0）

### 操作手順

1. 読み上げたいテキストを表示する
2. ツールバーの読み上げボタン、またはブロックの読上げボタンをクリック
3. 選択中の TTS エンジン（設定タブで切替）で読み上げられる

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| TTS エンジン | edge / WebSpeech / Plachta から選択 | edge |
| エンジン別チャンク上限 | edge 100〜2000 / webspeech・plachta 50〜140（v0.18.0） | edge 500 / 他 140 |
| 自動読み上げ | タスク終了時（📢 報告）に自動で読み上げる（v0.11.0） | ON |
| 自動読み上げ範囲 | 📢 ヘッダーのみ / メッセージ全文（v0.13.0〜） | header |
| 最終回答のみ | 複数ターンタスクで最終回答のみ読み上げ（v0.19.0） | ON |
| 読み上げフィルタ | 絵文字/顔文字/ASCII/短コード/コールアウト/テーブル/コード/思考をタイプ別に除外（v0.17.0） | 各 ON |
| AI読み上げボタン | ✨ ボタンの表示/非表示（v0.16.0） | ON |

### 注意点

- 読み上げ中に新しい報告が来た場合は**最新を優先**（latest-wins）
- ミュート中は読み上げません

## 🔧 MD 保存ボタン（v0.17.0）

> Claudian の回答ブロック・ツールバーから **Markdown ファイルを保存**します。

### 入口

- 回答ブロック右クリック → 「MD 保存」/ ツールバーの 📄 ボタン

### 操作手順

1. 保存したい回答を表示する
2. ツールバーの 📄 ボタン（または回答ブロック右クリック → MD 保存）をクリック
3. 保存先を選択（Memory フォルダ等）

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| Memory フォルダ | 保存先フォルダ（設定画面 Memory タブ） | Memory/ |

### 注意点

- ファイル名衝突時は自動的に別名で保存されます

## 🔧 右クリックバックアップ（v0.21.0）

> ファイルツリーからフォルダ/ファイルを右クリックで **タイムスタンプ付きバックアップ**を作成します。

### 入口

- ファイルエクスプローラでフォルダ/ファイルを右クリック → 「💾 バックアップ」

### 操作手順

1. バックアップしたいフォルダ/ファイルを右クリック
2. 「💾 バックアップ」をクリック
3. 保存先ダイアログで保存先を選択
4. タイムスタンプ付きでコピーされ、完了後 1.5 秒でダイアログ自動クローズ（v0.21.1）

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| バックアップ有効 | 右クリックメニューへの表示/非表示 | ON |
| 完了時自動クローズ | バックアップ成功後にダイアログを自動で閉じる | ON |

### 注意点

- 失敗時はダイアログを閉じず、エラーログを確認できます

## 🔧 Chroma-fs 仮想フォルダ + RAG（v0.20.0）

> Chroma DB の内部構造をファイルエクスプローラから隠し、`chroma_db` ドキュメントに **右クリック RAG 検索**を追加します。

### 入口

- `chroma_db` 内のドキュメントを右クリック → RAG 質問モーダル

### 操作手順

1. 設定画面「Chroma」タブで `chroma_db` を有効化
2. `chroma_db` 内のドキュメントを右クリック → RAG 質問モーダルを開く
3. 質問を入力 → バックエンド（`word-pdf-rag query.py --json`）で検索結果を取得

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| hideInternal | `chroma_db` 内部をファイルエクスプローラから非表示 | ON |
| rag | 右クリック RAG 検索メニューの有効化 | ON |

## 🔧 アンダースコアフォルダ非表示（v0.22.0）

> フォルダ名の先頭が `_` のフォルダ（例: `_テンプレート`）をファイルエクスプローラから非表示にします。

### 入口

- 設定画面「拡張子フィルタ」タブ → 「`_` プレフィックスフォルダ非表示」トグル

### 操作手順

1. 設定 → 拡張子フィルタタブを開く
2. 「`_` プレフィックスフォルダ非表示」を ON にする
3. ファイルエクスプローラから `_` フォルダが非表示になる

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| アンダースコアフォルダ非表示 | `_` プレフィックスフォルダを常に非表示（「フォルダは常に表示」より優先） | ON |

## 🔧 クイック返信ボタン全体の ON/OFF（v0.25.0）

> ツールバーに **✅ ❌ 1️⃣2️⃣3️⃣4️⃣5️⃣** のクイック返信ボタンを表示する/しないを切り替えます。

### 入口

- 設定画面「一般」タブ → **「クイック返信ボタンを表示」**トグル

### 操作手順

1. 設定 → 一般タブを開く
2. **「クイック返信ボタンを表示」を OFF** にすると、ツールバーからクイック返信ボタンが即時消える
3. **ON** に戻すと再表示される

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| クイック返信ボタンを表示 | OFF で注入停止 + 既存ボタン削除 / ON（既定）で注入再開 | ON |

### 注意点

- OFF にしていても Claudian 本体の動作には影響しません（Claudian Bridge の機能のみ停止）
- 方案提案の表示制御（`quickReplyShowAllOptions`）は別設定です。両方とも OFF にすると「快速返信なし + 方案提案のみ表示」となります

## 🔧 クイック返信ボタン（方案ボタン常時表示）v0.24.0

> クイック返信ボタンの方案ボタン（1️⃣〜5️⃣）を**常に表示する**かどうかを設定できます。

### 入口

- 設定画面「一般」タブ → **「方案ボタンを常に表示」**トグル

### 操作手順

1. 設定 → 一般タブを開く
2. **「方案ボタンを常に表示」を ON** にする
3. ツールバーに ✅ ❌ 1️⃣2️⃣3️⃣4️⃣5️⃣ が**常に表示**されるようになる

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| 方案ボタンを常に表示 | ON で 1️⃣〜5️⃣ を常時表示 / OFF（既定）は応答の「方案N」検出時のみ表示 | OFF |

### 注意点

- OFF（既定）の場合、LLM 応答に「方案1」「方案2〜5」などが含まれないと方案ボタンは表示されません
- ON の場合、推奨方案のハイライト（背景色強調）は引き続き有効です

## 🔧 AI読み上げボタン（✨）v0.16.0

> 入力欄に書いた文章を **AI が「意図を解釈した分かりやすい指令文」に整形**し、入力欄を上書きして**読み上げる**機能です。

### 入口

- ClaudianChat の入力ツールバー（入力欄の下）右側にある **✨ ボタン**

### 操作手順

1. ClaudianChat の入力欄に文章を入力する（例:「あれやっといて」）
2. **✨ ボタン**をクリックする
3. 数秒待つ（⏳ 表示中は Claude Code CLI が整形処理中）
4. 入力欄が**整形された指令文**に上書きされ、その文が**読み上げられる**
5. 上書き前に書いた元文は **Notice（画面下部の通知）** に表示されるため、コピーして復元できる

### 整形の例

| 入力（元の文） | 整形後の指令文（例） |
|----------------|----------------------|
| あれやっといて | それを実行しておいてください。 |
| 昨日のやつ直して | 昨日指摘された箇所を修正してください。 |

### 設定項目

| 設定項目 | 説明 | デフォルト値 |
|--------|------|--------|
| AI読み上げボタン | ClaudianBridge 設定 → TTS タブ。OFF で ✨ ボタンを非表示化 | ON |

### 読み上げ音声

- 既存の読み上げ設定（**TTS エンジン**: edge / webspeech / plachta）に従います
- 整形後の言語は**入力と同じ言語**を維持します

### 注意点

- ✨ ボタンは **Claude Code CLI（`claude -p`）** を呼び出すため、初回は数秒〜10 秒程度かかることがあります
- CLI が失敗した場合は**元の文のまま読み上げ**ます（入力欄は変更されません）
- 入力欄が空、またはミュート中の場合は読み上げず通知を表示します
- 整形 LLM に追加の API キー設定は不要です（Claude Code の既存設定を利用）

## 🔧 MD 読み上げハイライト（v0.33.0 / F-028）

> MD ファイルを **Preview モード**で開いた状態で右クリック「Add to TTS」を押すと、本文を読み上げつつ **今読まれているチャンク位置に背景色ハイライト** がつきます。**フローティングオーバーレイ**（画面右上）から一時停止・次の見出しスキップ・ミュート・進捗（N / M チャンク）を操作できます。

### 使い方

1. MD ファイルを **Preview モード**で開く（Live Preview / Source モードでは機能しません）
2. ファイルエクスプローラで対象 MD を **右クリック → Add to TTS**
3. 右上にフローティングオーバーレイ（⏸ ⏭ 🔇 N/M）が表示される
4. 読み上げ中は本文の該当チャンクがハイライトされる
5. ⏸ で一時停止、⏭ で次の見出し（H1〜H3）にスキップ（隣接チャンクのみなら no-op）、🔇 でミュート

### 設定

`ClaudianBridge 設定 → TTS タブ → 「MD 読み上げハイライト」セクション` で以下をカスタマイズできます：

- **有効化トグル**: デフォルト ON。OFF にすると従来挙動（ハイライト・overlay なし）
- **ハイライト色**: `#aabbcc` 形式（3 桁・6 桁両対応）。空文字なら `rgba(100, 180, 255, 0.35)` のデフォルト

### 動作モード

| モード | 挙動 |
|------|------|
| Preview | ✅ ハイライト + オーバーレイ表示 |
| Live Preview | ⚠️ 「Preview モードで表示中のみハイライトできます」通知。再生は通常通り継続 |
| Source モード | ❌ 機能停止（DOM 構造の問題によりフォーカス外）|

### スコープ外（YAGNI）

- 単語単位ハイライト（webspeech 限定）→ 全エンジン対応要件によりチャンク単位で妥協
- ⏮ 巻き戻し → ⏭ スキップで代替
- 進捗バー → N/M 文字表記で十分
- Live Preview 対応 → DOM 不整合のため Preview 限定
- 別 MD への遷移時の継続再生 → 単一 MD 完結

> ⚠️ **互換性**: 既存の MD 右クリック Add to TTS（v0.17.0）経路を壊さず、機能を追加するのみ。ハイライトを OFF にすれば従来挙動に戻ります。
