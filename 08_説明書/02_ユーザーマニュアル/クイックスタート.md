## 📥 手順 1: ダウンロード・インストール

### Android

1. Google Play / アプリストアを開く
2. 「[製品名]」を検索
3. 「インストール」をタップ

### その他のプラットフォーム

> [!info] その他のプラットフォームは開発中
> iOS／Web版はまもなくリリース予定

---

## ⚙️ 手順 2: 初回設定

### API Key の設定

1. アプリの設定を開く
2. AI Provider を選択
3. API Key を入力
4. 保存をタップ

> [!tip] API Key をお持ちでない場合
> [Provider 公式サイト] にアクセスして API Key を取得してください
