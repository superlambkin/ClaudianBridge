## 📱 機能詳細

### F-001 テキスト挿入

**機能説明**

ノート・プレビュー・Canvas・realclaudian チャット領域でテキストを選択すると、フローティングポップアップが表示される。「Add to Claudian」をクリックすると選択テキストが Claudian チャットの入力欄へ挿入される（`realclaudian.activateView → appendToActiveInput`）。

**利用シーン**

- Web やノートの一部を引用して Claude に相談するとき
- 断片的なメモをそのままチャットへ送るとき

**技術ポイント**

- 実装: `features/selection/{core,watcher,popup}.ts`
- 選択監視は `delayMs`（既定 300ms）の遅延後にポップアップ表示
- realclaudian 未検出・ビュー未準備・挿入失敗時は Notice 警告（NoOp）

---

### F-002 音声読み上げ（TTS）

**機能説明**

選択テキスト・チャット応答・MD ファイル本文を 3 エンジンで音声読み上げする。

| エンジン | 方式 | 特徴 |
|------|------|------|
| `edge`（既定） | POC_015 claude-tts スキルを python spawn で呼ぶ HTTP ブリッジ | 高品質・チャンク上限 500 字（設定可） |
| `webspeech` | ブラウザ標準 Web Speech API | 追加依存なし・オフライン |
| `plachta` | Plachta Cloud VITS（HF Space / SSE） | 9 プリセット + カスタム 200 種・話速 0.5〜2.0 |

**利用シーン**

- 長文の要点を音声で確認するとき
- タスク終了時に最終回答を自動読み上げ（`autoRead`）
- チャット応答の各ブロックを読上げボタンで個別再生

**技術ポイント**

- 実装: `features/tts/{core,speak,chunking,speech-filter,auto-read,...}.ts`
- 全エントリポイントは統合 `speakText` 経由（v0.17.0）
- タイプ別読み上げフィルタ 8 項目（絵文字/顔文字/ASCII/短コード/コールアウト/テーブル/コード/思考/ツール）

### F-003 フォルダ参照追加

**機能説明**

ファイルエクスプローラでフォルダ右クリック →「Add to Claudian」で `@<フォルダパス> ` を Claudian 入力欄へ挿入する。

**利用シーン**

- 資料フォルダを Claude に参照させるとき

**技術ポイント**

- 実装: `features/selection/core.ts`（`addFolderToClaudian`）
- `selection.folderEnabled=true` 時のみメニュー表示

### F-004 Office 変換

**機能説明**

ファイル右クリック →「Convert to Markdown」「Convert & Split」「Convert all (N) to Markdown」で Office/PDF/HTML/CSV を Markdown に変換する。Python + markitdown を spawn。

**利用シーン**

- Word/Excel/PDF の資料を Vault の MD ノートとして取り込み
- 進捗モーダル + ConversionSummary 表で結果確認

**技術ポイント**

- 実装: `features/office/{converter,markitdown,splitter,frontmatter,path,menu,...}.ts`
- frontmatter テンプレートで変換 MD にメタ情報を付与
- 競合ポリシー: overwrite / skip / timestamp

**利用シーン**

**技術ポイント**

### F-013 AI読み上げボタン（v0.16.0）

**機能説明**

ClaudianChat の入力ツールバー右端の ✨ ボタンで、入力文を **Claude Code CLI（`claude -p`）** が「意図を解釈した分かりやすい指令文」に整形し、**入力欄を上書き**して **既存の TTS エンジン**で読み上げる。設定タブ（TTS → AI読み上げボタン）で無効化できる。

**利用シーン**

- 口語・断片的なメモを、Claude に送る前に**明確な指示文へ整えたい**とき
- 入力内容を**音声で確認**したいとき（整形後の文を読み上げ）
- 整形に失敗しても**元の文をそのまま読み上げる**ため、入力内容を失わない

**技術ポイント**

- 整形 LLM: Claude Code CLI（API キー追加設定不要・stdin 渡し・30 秒タイムアウト・入力と同一言語を維持）
- 上書き後は元文を Notice に表示（コピーで復元可能）
- 実装: `features/tts/input-ai-read-button.ts` + `features/llm/claude-cli.ts`

### F-015 Chroma-fs RAG 検索（v0.20.0）

**機能説明**

chroma_db フォルダの内部ファイル（`.db` 等）をファイル一覧から非表示化しつつ、フォルダ右クリック →「RAG 検索」で質問を投げると `word-pdf-rag query.py` 経由で類似文書を検索する。質問モーダルから実行。

### F-016 右クリックバックアップ（v0.21.0）

**機能説明**

ファイルツリーでフォルダまたはファイルを右クリック →「💾 バックアップ」→ 保存先ダイアログ → **タイムスタンプ付きコピー**を作成する。設定画面「一般」タブで ON/OFF 切替可能。

**技術ポイント**

- 実装: `features/backup/{backup-menu-registrar,backup-runner}.ts`
- コピーは `fs.promises.cp` で実行。保存先ダイアログは Electron `dialog.showOpenDialog`（フォールバック: `remote.dialog`）
- 完了後 1.5 秒でダイアログ自動クローズ（v0.21.1・`general.backupAutoClose`）

### F-017 アンダースコアフォルダ非表示（v0.22.0）

**機能説明**

フォルダ名の先頭が `_` のフォルダ（例: `_テンプレート`）をファイルエクスプローラから**常に非表示**にする。設定画面「拡張子フィルタ」タブで ON/OFF 切替可能（既定 ON）。「フォルダは常に表示」より優先される。

**技術ポイント**

- 実装: `features/whitelist/css-builder.ts`（`data-path*="/_"` セレクタで CSS 注入）
- 設定: `whitelist.hideUnderscoreFolders`（既定 true）

## 🆕 v0.38.0 新機能（F-038）

### F-038-1 文生図機能

**機能説明**

リボン 🎨 アイコン or コマンドパレット「Text-to-Image」からモーダルを開き、プロンプト + プロバイダ + アスペクト比を指定して画像を生成。生成画像は `<Vault>/output/Assets/text2img_<YYYYMMDD>_<hash>.{png,jpg}` に保存され、アクティブノートに `![[filename]]` が自動挿入される（ノート無しなら `Untitled.md` を新規作成）。

**利用シーン**

- LLM 応答にイラストが必要なとき
- ブログ記事 / SNS 投稿用のサムネイル生成
- ノートに直接画像を貼りたいとき

**対応プロバイダ**

- **MiniMax image-01**: `quota.minimaxApiKey` を使用（既存設定流用）
- **Zhipu GLM-Image**: `quota.zhipuApiKey` を使用（既存設定流用）

### F-038-2 画像スタイル選択

**機能説明**

モーダル内の「スタイル」ドロップダウンで 4 種から選択。プロンプト先頭に英語スタイル指示を自動付与する。

| スタイル | 用途 | プレフィックス例 |
|---------|------|-----------------|
| **standard**（既定） | スタイル指示なし | （無し）|
| **scientific** | 図解・インフォグラフィック風 | `Scientific illustration, clean infographic style, 16:9 layout, ...` |
| **anime** | アニメ・イラスト風 | `Anime style illustration, Studio Ghibli aesthetic, vibrant colors, ...` |
| **photo** | 写真リアル風 | `Photorealistic photograph, high resolution 4K, ...` |

### F-038-3 LLM プロキシ設定

**機能説明**

設定 → ClaudianBridge → 一般タブ → 「🌐 プロキシ設定」セクションで社内プロキシ URL を設定。有効化すると、LLM アクセス（画像生成・残量検知）がプロキシ経由になる。設定変更は即時反映（次リクエストから有効）。

**設定項目**

| 項目 | 説明 | 例 |
|------|------|-----|
| **enabled** | プロキシ使用の有効/無効 | `true` / `false` |
| **url** | プロキシ URL | `http://proxy.example.com:8080` |
| **noProxyHosts** | プロキシ除外ホスト（カンマ区切り） | `localhost,127.0.0.1,.local` |

**技術詳細**

- Obsidian の `requestUrl` は `HTTPS_PROXY` 環境変数を尊重しないため、本機能では proxy 検出時に Node 18+ `fetch`（undici）にフォールバックして proxy 経由通信を実現
- 除外ホスト（`localhost` / `127.0.0.1` / `*.local`）は常にプロキシスキップ
