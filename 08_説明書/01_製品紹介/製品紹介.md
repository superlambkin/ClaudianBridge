# 📦 製品紹介 — Claudian Bridge

## 🎯 一言紹介

> **Obsidian での Claude（ClaudianChat）利用を「選択 → 挿入 / 読み上げ / 変換 / 保存」で完結させる、Claudian 統合プラグイン。**

---

## 📖 製品概要

### 背景

ClaudianChat（realclaudian）と Claude Code CLI を使ったワークフローは、テキスト挿入・音声読み上げ・Office 変換・拡張子フィルタなどが複数のプラグインに分散し、設定の二重管理や挙動不一致が発生していた。Claudian Bridge はこれらを **1 プラグイン** に統合し、設定・データ移行・運用を一元化する。

### 対象ユーザー

| ユーザー像 | 利用シーン |
|----------|----------|
| Obsidian + Claude を毎日使う知識労働者 | ノートの引用を Claudian へ送信・音声で確認 |
| 資料を Vault に取り込みたいユーザー | Office/PDF/HTML/CSV を Markdown 化 |
| LLM API 残量を管理したいユーザー | 5 プロバイダの残量をインジケータで監視 |
| ナレッジベース検索をしたいユーザー | Chroma DB への RAG 検索 |

### 核心価値

| 価値軸 | 説明 |
|----------|------|
| **効率向上** | テキスト挿入・読み上げ・変換・保存をワンクリックで実行 |
| **コスト削減** | 5 プラグイン → 1 プラグイン（保守コスト 67% 削減） |
| **体験改善** | 設定 1 画面（8タブ）・自動データ移行・旧プラグイン自動無効化 |

---

## 🎯 主要機能

| 機能 | 説明 |
|------|------|
| **テキスト挿入 / フォルダ参照** | 選択テキストやフォルダを ClaudianChat 入力欄へ挿入 |
| **音声読み上げ（3 エンジン）** | edge-TTS / WebSpeech / Plachta Cloud VITS |
| **Office 変換** | Office/PDF/HTML/CSV → Markdown |
| **拡張子フィルタ** | ファイル一覧を拡張子で絞り込み |
| **LLM 残量検知** | 5 プロバイダの残量を信号色で表示 |
| **Chroma DB ブラウザ + RAG 検索** | ベクターDBの閲覧・検索・RAG |
| **AI読み上げボタン / MD 保存** | 入力文の AI 整形読み上げ・回答の MD 保存 |

## 🔗 POC_015（ClaudeTTS）との関係

| バージョン | 内容 |
|:------:|------|
| **v0.10.0** | ClaudeTTS（`voice-config.json`）設定融合 — Claudian Bridge を SSOT として CLI 設定と双方向同期 |
| **v0.13.0** | **CLI Stop hook 由来の読み上げを廃止** — 読み上げ経路を Claudian Bridge プラグインに一元化（二重読み上げ・ミュート非連動を解消） |
| **v0.11.1** | 旧 **claude-tts-settings プラグインを無効化**（ボタン二重注入と設定非同期の解消） |

> POC_015 の TTS スキル（`~/.claude/skills/claude-tts/`）は **Claudian Bridge が音声エンジン（edge-TTS）として呼び出す** 連携関係に整理された。
