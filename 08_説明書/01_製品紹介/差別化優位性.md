## ✨ 核心強み

### 1. 5 プラグイン → 1 プラグインの統合

Claudian Selection Bridge / 拡張子WhiteList / Vault Office Bridge / Chroma Inspector / claude-tts-settings を 1 本に統合。設定画面 1 つ（8タブ）・データ移行自動・旧プラグイン自動無効化で、管理コストを 67% 削減。

### 2. TTS の 3 エンジン + 自動読み上げの完成度

edge-TTS（高品質）/ WebSpeech（オフライン）/ Plachta Cloud VITS（アニメ声優調）を選択可能。タスク終了時の自動読み上げは **最終回答ゲート**（v0.19.0）で複数ターンタスクでも思考ブロックを読まず最終回答だけを確実に読み上げる。

### 3. LLM 残量検知 + Chroma RAG の統合

5 プロバイダ（Anthropic / DeepSeek / Kimi / MiniMax / Zhipu）の残量を信号色インジケータで一元監視。Chroma DB ブラウザ + chroma-fs（仮想フォルダ非表示 + 右クリック RAG 検索）でナレッジベース検索もプラグイン内で完結。

## 🔗 POC_015（ClaudeTTS）との差別化・関係

| 観点 | 内容 |
|------|------|
| **統合先** | v0.10.0 で `voice-config.json` 設定融合 — Claudian Bridge を **SSOT** として CLI 設定と双方向同期 |
| **一元化** | v0.13.0 で **CLI Stop hook 読み上げを廃止** — 読み上げ経路をプラグインに一本化（二重読み上げ・ミュート非連動を解消） |
| **無効化** | v0.11.1 で旧 **claude-tts-settings プラグインを無効化**（ボタン二重注入と設定非同期の解消） |
| **残る役割** | POC_015 の claude-tts スキルは edge-TTS の音声エンジンとして Claudian Bridge から呼び出される |

> **差別化の要点**: 読み上げの「入口（自動/手動/ボタン）」「制御（ミュート/停止）」「設定（SSOT）」をすべて Claudian Bridge に集約し、CLI 側の役割を音声エンジン提供に限定した。
