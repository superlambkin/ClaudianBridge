# 📖 05_デプロイ運用 · 技術用語対照表

## 🚀 ビルド・デプロイ用語

| 日本語 | 英語 | 説明 |
|------|------|------|
| ビルド | build | ソースコードを実行可能な成果物（main.js）へ変換 |
| バンドル | bundle | 複数モジュールを 1 ファイルに結合 |
| ミニファイ | minify | コードを圧縮（変数名短縮・空白除去） |
| デプロイ | deploy | 成果物を実行環境へ配置 |
| マーカー検証 | marker verification | 成果物に期待文字列が含まれるか検証 |
| デプロイ先 | deploy target | `.obsidian/plugins/claudian-bridge/` |
| ウォッチ | watch | ファイル変更を監視し自動再ビルド |
| ホットリロード | hot reload | 再起動なしで変更を反映 |

## 🧪 テスト用語

| 日本語 | 英語 | 説明 |
|------|------|------|
| 単体テスト | unit test | 関数・モジュール単位のテスト |
| 統合テスト | integration test | モジュール間連携のテスト |
| 合格 | passed | テスト成功 |
| スキップ | skipped | 環境依存等で実行省略 |
| 型チェック | typecheck | 静的型検査（tsc -noEmit） |

## 🐳 監視・運用用語

| 日本語 | 英語 | 説明 |
|------|------|------|
| 診断ログ | diagnostic log | 実行時の状態を記録するログ |
| アラート | alert | 異常を通知する仕組み |
| 残量検知 | quota detection | API 利用残量を監視 |
| インジケータ | indicator | 状態を色等で表示する UI |
| ロールバック | rollback | 前バージョンへ戻す操作 |
| バックアップ | backup | データ退避 |

## 🔌 本プロジェクト固有用語

| 用語 | 説明 |
|------|------|
| **claudian-bridge** | プラグイン ID（Obsidian の manifest id） |
| **Claudian Bridge** | プラグイン表示名 |
| **voice-config.json** | POC_015 由来の CLI 用音声設定（Claudian Bridge が SSOT 同期） |
| **Plachta Cloud VITS** | HuggingFace Space 上の TTS API |
| **obsidian-deploy.mjs** | 共有デプロイスクリプト（`D:\AI-Agent\_devtools\`） |
| **chroma_db** | Chroma ベクターデータベースのフォルダ |
| **RAG 検索** | Retrieval-Augmented Generation（類似文書検索） |
