# 📊 監視アラート

## 📐 概要

Claudian Bridge はローカルプラグインのため、**常設監視基盤（Prometheus/Grafana 等）は不要**。
監視は「アプリ内の診断ログ」「Quota 残量インジケータ」「開発時のデプロイ検証」で代替する。

---

## 🔍 監視対象と確認方法

| 監視対象 | 確認方法 | しきい値 / 目安 |
|------|------|------|
| **プラグインロード** | Developer Console の `[claudian-bridge] loaded` | ロード成功が前提 |
| **診断ログ** | `[cb-*]` / `[cb-diag]` プレフィックス | エラー（ERROR）が出ていないか |
| **グローバルエラー** | `installGlobalErrorHandlers` 出力 | 未捕捉例外が発生していないか |
| **Quota 残量** | realclaudian 隣の信号色インジケータ | 🟢 50% 以上 / 🟡 20〜50% / 🔴 20% 未満 |
| **TTS 失敗** | Notice + 診断ログ | Plachta / edge / webspeech のエラー通知 |
| **デプロイ検証** | 共有スクリプトのマーカー検証 | 欠落時 exit 1 でデプロイ失敗 |

---

## ⚠️ アラートルール

| レベル | 条件 | 対応 |
|:----:|------|------|
| 🔴 重大 | プラグインがロードされない（`[claudian-bridge] loaded` なし） | 設定・ビルド成果物を確認・再デプロイ |
| 🟠 高 | Quota 残量 20% 未満（🟡/🔴 表示） | キーの切り替え・補充 |
| 🟡 中 | TTS / Office 変換のエラー Notice が頻発 | 外部 API（HF Space / Python）状態を確認 |
| 🟢 情報 | デプロイのマーカー検証警告 | ビルド成果物の stale 確認 |

---

## 🛠️ 診断ログの見方

| プレフィックス | 内容 |
|------|------|
| `[claudian-bridge]` | モジュールロード / onload フロー |
| `[cb-tts]` | 再生検知・ステータス表示 |
| `[cb-diag]` | 診断イベント（import / migrate / voice-config 等） |
