## 📋 日常点検

| # | 項目 | 頻度 | 内容 |
|---|------|:----:|------|
| 1 | Quota 残量確認 | 週次 | realclaudian 隣のインジケータで各プロバイダ残量を確認 |
| 2 | プラグイン動作確認 | 週次 | テキスト挿入 / TTS / Office 変換が正常に動作するか |
| 3 | 診断ログ確認 | 月次 | Developer Console で `[claudian-bridge]` エラーを確認 |
| 4 | 旧プラグイン不在確認 | 月次 | `.obsidian/plugins/` に旧プラグインが残っていないか |

---

## 🔄 バージョンアップ手順

```bash
cd D:\AI-Agent\ClaudianBridge
git pull                 # 1. 最新ソース取得
npm ci                   # 2. 依存インストール
npm run typecheck        # 3. 型チェック
npm test                 # 4. テスト（592 passed / 1 skipped）
npm run build            # 5. ビルド + デプロイ + マーカー検証
```

- ビルド後に Obsidian でプラグインを再読み込み（または Hot-Reload に任せる）
- 設定画面のバージョン表示で反映を確認

---

## 🐛 トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| プラグインが読み込まれない | ビルド成果物の不整合 | `npm run build` で再デプロイ + マーカー検証 |
| TTS が失敗する | Plachta HF Space 停止 / API 変更 | 診断ログ確認 + エンジン切替 |
| Office 変換が失敗する | Python / markitdown 未導入 | `office.pythonPath` を確認（Windows 既定 `py`） |
| Quota 残量が表示されない | API キー未設定 / 更新間隔 | Quota タブでキー・`quotaEnabled` を確認 |
| 二重読み上げ | 旧 claude-tts-settings が再有効化 | 旧プラグインを無効化（`_disabled__` 維持） |
