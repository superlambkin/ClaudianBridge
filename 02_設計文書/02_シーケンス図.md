# 🔄 シーケンス図

> 📖 **シーケンス図って何？**
> **シーケンス図** は「複数の登場人物（プログラム）が、どの順番で何をするか」を時系列で表した図です。
> 例えるなら、レストランのやり取りを「客→店員→厨房」の順に矢印で書き出したようなものです。誰が誰に何を渡すかが一目で分かります。
> 図中の「→」は「依頼やデータを送る」ことを意味します。

本書は Claudian Bridge v0.8.0 の主要フローを [[../../POC_017_ClaudianBridge]] の実コードを SSOT（唯一の情報源）として Mermaid `sequenceDiagram`（処理の順序を図で表現）で記述する。

## 🖱️ F001: 選択ポップアップ → realclaudian 連携

```mermaid
sequenceDiagram
    autonumber
    actor U as ユーザー
    participant Obs as Obsidian
    participant SW as SelectionWatcher「選択監視プログラム」
    participant Pop as 選択ポップアップ
    participant CB as ClaudianBridgePlugin
    participant RC as realclaudian「Claude AI 送信機能拡張」

    U->>Obs: テキスト選択
    Obs->>SW: selectionchange / pointerup
    activate SW
    SW->>SW: enabled / スコープ / 長さチェック
    SW->>SW: setTimeout(delayMs)
    deactivate SW

    ...delayMs 後...

    SW->>Pop: buildPopup + appendToBody + positionPopup
    Pop-->>U: 「Add to Claudian」「Add to TTS」表示

    alt Add to Claudian
        U->>Pop: クリック
        Pop->>SW: onClaudian コールバック
        SW->>SW: cancelAndHide
        SW->>CB: addTextToClaudian(app, text)
        CB->>RC: plugins.plugins['realclaudian'] 取得
        CB->>RC: activateView()
        CB->>RC: getView().appendToActiveInput(text)
        RC-->>CB: true / false / 例外
        CB-->>U: Notice 成功 or 失敗
    else Add to TTS
        U->>Pop: クリック
        Pop->>SW: onTts コールバック
        SW->>SW: cancelAndHide
        SW->>CB: addTextToTTS(app, text, cfg.tts)
        CB-->>U: Notice 成功 or 失敗
    end
```

### ポップアップ制御の補足

| イベント | SelectionWatcher の動作 |
|------|------|
| pointerdown | `pointerDown=true`、ポップアップ外なら `dismissed=true` で消去 |
| pointerup | ポップアップ内ならクリックを届ける；外なら `onSelectionChange` 再判定 |
| scroll / blur / Escape | `cancelAndHide` |
| pointerInPopup | クリック中はポップアップを消さないガード |

## 🔊 F002: TTS 読み上げ（エンジン分岐）

```mermaid
sequenceDiagram
    autonumber
    actor U as ユーザー
    participant CB as ClaudianBridgePlugin
    participant TC as features/tts/core
    participant Edge as claude-tts (commands.py)
    participant WS as Web Speech API
    participant PC as Plachta Cloud HF Space

    U->>CB: 「Add to TTS」クリック
    CB->>TC: addTextToTTS(app, text, settings)
    TC->>TC: engine 分岐

    alt engine == 'edge'
        TC->>Edge: spawn python commands.py speak
        TC->>Edge: stdin.write(text) / end
        Edge-->>TC: exit 0 / stderr
        TC-->>U: Notice 成功 or 失敗
    else engine == 'webspeech'
        TC->>TC: pickWebSpeechLang(text)
        TC->>WS: SpeechSynthesisUtterance + voice マッチ
        TC->>WS: speechSynthesis.speak()
        WS-->>TC: 100ms後に optimistic resolve
        TC-->>U: Notice 成功 or 失敗
    else engine == 'plachta'
        TC->>PC: POST /call/tts_fn
        Note right of TC: data: [text, speaker, language, speed, false]
        PC-->>TC: { event_id }
        loop 最大60回 × 1秒
            TC->>PC: GET /call/tts_fn/{eventId}/results
            PC-->>TC: { data: [status, url] }
        end
        TC->>PC: fetch(wavUrl)
        PC-->>TC: audio/wav bytes
        TC->>TC: Blob + URL.createObjectURL + Audio.play()
        TC-->>U: Notice 成功 or 失敗
    end
```

### 各エンジンの詳細フロー

#### F002-1 edge-tts（ClaudeTTS HTTP ブリッジ経由）

```mermaid
sequenceDiagram
    participant TC as TTS Core
    participant SP as child_process.spawn
    participant PY as ~/.claude/skills/claude-tts/scripts/commands.py

    TC->>SP: spawn('python', [cmd, 'speak'])
    activate SP
    SP->>PY: commands.py speak
    TC->>SP: stdin.write(text)
    TC->>SP: stdin.end()
    PY-->>SP: stdout / stderr
    SP-->>TC: close(code)
    deactivate SP
    alt code === 0
        TC-->>TC: resolve(true)
    else code !== 0
        TC-->>TC: resolve(false) + Notice
    end
```

#### F002-2 Web Speech（ブラウザ API）

```mermaid
sequenceDiagram
    participant TC as TTS Core
    participant Win as window
    participant Syn as speechSynthesis

    TC->>TC: pickWebSpeechLang(text)
    TC->>Win: new SpeechSynthesisUtterance(text)
    TC->>Syn: getVoices()
    Syn-->>TC: 利用可能 voice リスト
    TC->>TC: settings.voices.webspeech[lang] とマッチ
    TC->>Syn: speak(utterance)
    Syn-->>TC: 再生開始
    TC-->>TC: setTimeout(()=>resolve(true), 100)
```

#### F002-3 Plachta Cloud VITS

```mermaid
sequenceDiagram
    participant TC as TTS Core
    participant API as Plachta HF Space

    TC->>TC: resolveSettings(speaker, language, speed)
    TC->>API: POST /call/tts_fn
    API-->>TC: event_id
    loop i = 0 .. 59
        TC->>API: GET /call/tts_fn/{event_id}/results
        API-->>TC: { data: [status, url] }
        opt status === 'ok'
            TC->>API: fetch(url)
            API-->>TC: wav ArrayBuffer
            TC->>TC: Blob + URL.createObjectURL
            TC->>TC: new Audio().play()
        end
        opt status startsWith 'error'
            TC-->>TC: resolve(false) + Notice
        end
    end
    opt 60秒経過でも wavUrl 未取得
        TC-->>TC: resolve(false) + タイムアウト Notice
    end
```

## 📄 F003: Office → Markdown 変換

```mermaid
sequenceDiagram
    autonumber
    actor U as ユーザー
    participant Menu as OfficeMenuRegistrar
    participant Modal as ProgressModal
    participant Conv as OfficeConverter
    participant Runner as MarkItDownRunner
    participant Split as SplitterRunner
    participant PY as _run_markitdown.py / split_*.py

    U->>Menu: 右クリック → Convert to Markdown
    Menu->>Modal: new ProgressModal + open()
    Menu->>Conv: convertItem(file, {split:'single'}, settings, modal)

    Conv->>Modal: setStage('Reading source', running)
    Conv->>Conv: fs.promises.access(srcAbs)
    Conv->>Modal: setStage('Reading source', ok|fail)

    Conv->>Modal: setStage('Invoking markitdown', running)
    Conv->>Runner: run(srcAbs, settings, vaultRoot)
    Runner->>Runner: resolvePython(pythonPath)
    Runner->>PY: spawn python -u _run_markitdown.py srcAbs
    PY-->>Runner: JSON envelope {exitCode, stdout, stderr}
    Runner-->>Conv: MarkItDownResult
    Conv->>Modal: setStage('Invoking markitdown', ok|fail)

    Conv->>Conv: FrontmatterApplier.expand + sha256
    Conv->>Modal: setStage('Writing main .md', running)
    alt conflictPolicy == 'skip' and 既存
        Conv->>Modal: appendLog('[SKIP]')
    else
        Conv->>Conv: writeFile(mainAbs, fullMd)
    end
    Conv->>Modal: setStage('Writing main .md', ok|fail)

    opt split == 'split'
        Conv->>Modal: setStage('Splitting (optional)', running)
        Conv->>Split: split(ext, mdAbs, srcAbs, outDir)
        Split->>PY: spawn split_<ext>.py mdAbs srcAbs outDir
        PY-->>Split: stdout 行 = 出力ファイルリスト
        Split-->>Conv: SplitResult
        Conv->>Modal: setStage('Splitting (optional)', ok|fail)
    end

    Conv->>Modal: setProgress(100) + setButtonsEnabled
    Conv-->>Menu: ConversionItemResult
    Menu-->>U: Notice / 結果オープン
```

### StageStatus の遷移

| ステージ名 | StageStatus |
|------|------|
| Reading source | pending → running → ok / fail |
| Invoking markitdown | pending → running → ok / fail |
| Writing main .md | pending → running → ok / fail |
| Splitting (optional) | pending → running → ok / fail |

## 🧬 F005: Chroma 検索（Python CLI 経由）

```mermaid
sequenceDiagram
    autonumber
    actor U as ユーザー
    participant View as DatabaseBrowserView
    participant List as CollectionList
    participant Search as SearchPanel
    participant Rec as RecordCardView
    participant Svc as ChromaService
    participant PY as _chroma_inspect.py

    U->>View: サイドバー/コマンドで Chroma Browser 開く
    View->>View: onOpen()
    View->>Search: 検索パネル構築
    View->>List: コレクションリスト構築
    View->>Rec: レコードエリア構築

    View->>Svc: listCollections()
    Svc->>PY: python -u _chroma_inspect.py --json --path <db> list
    PY-->>Svc: JSON envelope {collections}
    Svc-->>List: setCollections

    U->>List: コレクション選択
    List->>View: onSelect(name)
    View->>View: runSearch(filter)

    alt queryText あり && embeddingModel 設定済み
        View->>Svc: query(text, nResults, filter)
        Svc->>PY: query --text ... --include metadatas,documents,distances
    else queryText あり && embeddingModel 未設定
        View->>Svc: where(documentContains = queryText)
        Note right of View: 設定未完了 → 文書内検索にフォールバック
    else メタデータ / 文書条件のみ
        View->>Svc: where(filter)
        Svc->>PY: where --collection ... --where <json> --key <word>
    else 条件なし
        View->>Svc: get(limit=nResults)
        Svc->>PY: get --limit ...
    end

    PY-->>Svc: JSON envelope {records}
    Svc-->>View: QueryResult / GetResult
    alt EmbeddingDimensionError
        Svc-->>View: throw
        View->>View: where フォールバック + Notice
    end
    View->>Rec: render(records)

    opt enableRawSql == true
        U->>Search: Advanced: Raw SQL ボタン
        Search->>View: onOpenRawSql()
        View->>RawSqlModal: open()
    end
```

### ChromaService 公開メソッド

| メソッド | Python CLI サブコマンド | 用途 |
|------|------|------|
| listCollections | `list` | 全コレクション取得 |
| get | `get` | 条件なし / ID 指定でレコード取得 |
| where | `where` | メタデータ + 文書内検索 |
| query | `query` | 埋め込みモデルを使った意味検索 |
| version | `version` | DB / Python 接続テスト |
