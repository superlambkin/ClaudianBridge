## 2. 現行仕様（v0.41.0 時点）

### 2.1 ツールバーボタン（ミュート + 📖 全文）

`setupToolbarButtons(store)` が `.claudian-input-toolbar` へ `MutationObserver` で注入（重複防止属性: `data-cb-mute` / `data-cb-fulltext`）。

**ミュートボタン（3 状態・アイコンのみ表示・説明は tooltip）**:

| 状態 | 判定 | 表示 | クリック動作 |
|------|------|------|-------------|
| `enabled-idle` | `tts.enabled && !isTtsPlaying()` | 🔊 ミュート | `tts.enabled=false` + `stopAllPlayback()` |
| `enabled-playing` | `tts.enabled && isTtsPlaying()` | 🔊 停止（点滅） | `stopAllPlayback()` のみ |
| `disabled` | `!tts.enabled` | 🔇 ミュート解除 | `tts.enabled=true` |

**📖 全文ボタン**: `withFullTextState(cfg, on)` ヘルパーで `tts.autoRead.scope`（header/full）と `tts.cli.full_text` を**常時同期**して保存（不変条件: `scope==='full' ⟺ full_text===true`）。

**状態同期**: 旧 claude-tts-settings の 3 秒ポーリングは廃止。`store.onSave()`（設定変更の即時反映）+ `playback-registry.onPlaybackChange()`（再生開始/終了の即時反映）のイベント駆動方式。`stopAllPlayback()` は edge=child.kill() / webspeech=synth.cancel() / plachta=audio.pause() の各ハンドルを一元停止し、意図的停止ではエラー Notice を抑制する。

### 2.2 メッセージ読上げボタン

`setupMessageReadButtons(deps)` が各 `.claudian-text-block` のコピーボタン（`.claudian-text-copy-btn`）の直前（`inset-inline-end:22px`・hover 表示）に `volume-2` アイコンのボタンを注入（マーカー: `data-cb-msg-read`）。

- クリックでブロックの可視テキスト（ボタン自身を exclude した `readVisibleTextExcluding` 相当）を取得し `addTextToTTS()` へ
- `tts.enabled=false` 時は `🔇 ミュート中` Notice で読上げない
- speech_filter（Emoji/Kaomoji 除去）・再生レジストリ・ミュート点滅連動は共通経路で自動適用

### 2.3 クイック返信ボタン

`setupQuickReplyButtons` 系（現行 `nav-buttons.ts`）が `.claudian-input-nav-actions` 内の **NewTab ボタン左隣**へ `.cb-quickreply-row` を注入（NewTab 不在時は非注入）。

| 項目 | 現行仕様 |
|------|---------|
| ボタン構成 | ✅（OK 送信）・ ❌（NG 送信）・ 方案 1️⃣〜5️⃣（`方案N` 送信） |
| アイコン | **SVG**（OK/NG は Lucide `check`/`x`、方案は `<svg><circle/><text>N</text></svg>` バッジ）。20x20・NewTab と同型 |
| 送信方式 | **直接送信**: `tab.dom.inputEl.value = text` → input イベント発火 → `controllers.inputController.sendMessage()`。非対応時は `appendToActiveInput`（挿入のみ）へフォールバック |
| 表示条件 | `general.quickReplyEnabled`（既定 **ON**）— OFF で注入停止 + 既存ボタン削除 |
| 方案ボタン表示数 | `Math.min(maxOptionCount, 5)` 個を動的表示（0 件時は ✅ ❌ のみ）。`general.quickReplyShowAllOptions`（既定 **OFF**）で 5 個常時表示 |
| 推奨ハイライト | `extractRecommendedOption()` が最終 assistant メッセージから推奨案（1〜5）を検出 → `.is-recommended`（アクセント背景）。検出パターンは ja/zh/en + `方案N` / `案N` / `👑N` / 数字（1/2/3）形式（v0.26.0 / v0.30.2 拡張） |
| 選択肢数検出 | `extractMaxOptionCount()` が `方案N` / `案N` の個別・範囲（`案1〜4` 等）表記の最大値を返す |
| 連打防止 | `busy` フラグ + `btn.disabled` |

| # | 廃止された仕様 | 置換後 | 契機 |
