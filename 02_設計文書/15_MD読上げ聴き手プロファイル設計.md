## 1. 背景・目的

Add to TTS で読み上げる内容を、聴き手の属性・シーンに応じて口調・専門用語の言い換え・トーンを適用する。職場メモ・顧客レビュー・家族共有・学生教材・上司報告・DR を同じ MD で読み上げ方だけ切替可能にする。

## 2. 要件（決定済み）

| # | 要件 | 決定 |
|:-:|------|------|
| R1 | プロファイル種別 | 7 種（原文 / 職場 / 顧客 / 家族 / 教室 / 上司 / DR） |
| R2 | 設定キー | `tts.mdReadProfile: string`（既定 `'original'`） |
| R3 | 用語辞書 | `tts.termsDict: string`（既定 `''`） |
| R4 | 設定 UI | テキスト読み上げタブにプルダウン追加 |
| R5 | 変換処理 | 既存フィルタ後に `applyProfileTransform()` を挟む |
| R6 | DR 警告音 | Web Audio API で生成した短音ビープ |
| R7 | 上司プロファイル | `🎯 結論` 見出しをチャンク配列の先頭に |
| R8 | キャッシュ | しない（毎回変換） |
| R9 | 用語辞書デフォルト | `00_Vault管理/Tech_用語対照表.md` |
| R10 | i18n | ja/zh/en すべてにプロファイル表示名 |

## 3. アーキテクチャ

```
input MD → extractMdText → filterSpeechText
   ↓
applyProfileTransform(text, profile, termsMap)
   ↓
chunkTextNatural → speakChunks
```

| コンポーネント | 責務 |
|------|------|
| `profile.ts`（新） | プロファイル enum・`applyProfileTransform()` |
| `terms-dict.ts`（新） | 指定パスから `用語 → やさしい表現` 表 |
| `audio-beep.ts`（新） | DR 用 Web Audio 短音 |
| 設定 UI | プルダウン・辞書パス |
| `speak.ts` 拡張 | 変換→ビープ→chunks |

## 4. プロファイル別動作

| プロファイル | 略語変換 | 口調 | 数字 | 警告音 | 並び順 |
|------|---|---|---|---|---|
| original | – | – | – | – | 元 |
| workplace | ✓（1 文字ずつ） | そのまま | 数字 | – | 元 |
| customer | ✓（一般語展開） | ですます | 数字 | – | 元 |
| family | ✓（口語化） | やさしい | 漢数字 | – | 元 |
| classroom | ✓（解説付記） | ていねい | 数字 | – | 元 |
| boss | – | 結論→根拠 | 漢数字 | – | 🎯 結論 先頭 |
| dr | – | 校正 | 数字 | ✓ 短音 | 元 |

## 5. UI

「テキスト読み上げ」タブの「ハイライト色」の上に追加：

| 項目 | UI |
|------|---|
| 聴き手プロファイル | プルダウン（7 種） |
| 用語辞書（任意） | テキスト入力（Vault パス） |

## 6. テスト

- workplace：`API` → `エー ピー アイ`
- customer：コードフェンス →「コードブロック省略」
- family：数字 → 漢数字
- classroom：用語辞書 → 解説付記
- boss：`🎯 結論` がチャンク先頭
- dr：警告音 API 呼出・誤字疑い箇所をビープで挟む
- original：変換なし（既存挙動）
- terms-dict：空ファイル / 存在しないパス no-op

## 7. 互換性

- `tts.mdReadProfile` 未設定 → `'original'` 既定
- `termsDict` 空 / パス不在 → 置換スキップ
- Web Audio API 未対応 → ビープスキップ（ログのみ）
