## 📐 概要

本章は Claudian Bridge（manifest 0.8.0）の重要な技術的決定について、**採用案 / 却下案**を比較する。すべての判定は実装コード（`src/` 配下）における事実関係に基づく。

> 📖 **処理方式比較って何？**
> 同じ問題を解決するには複数の方法があります。本書は「なぜこの方法を選び、他の方法を捨てたのか」を比較表で示します。
> 例えるなら「東京から大阪へ行く」方法を考えるとき、新幹線・飛行機・バス・徒歩のどれを選ぶか、費用・時間・快適さで比較するのと同じことです。ソフトウェア開発では「動作速度」「安全性」「壊れにくさ」で比較します。

## 📝 課題 1: プロセス起動

📍 該当: `src/features/chroma/chroma/chroma-runner.ts`, `src/features/office/` の spawn 周り

### 採用: `spawn(cmd, args, { shell: false })`

```typescript
child = spawn(opts.pythonPath, ["-u", opts.scriptPath, ...opts.args], {
  cwd: opts.cwd,
  env: { ...process.env, PYTHONIOENCODING: "utf-8" },
  shell: false,
  windowsHide: true,
});
```

| 観点 | 評価 |
|------|------|
| コマンドインジェクション | 🟢 ゼロ（argv 配列） |
| プラットフォーム差異 | 🟢 windowsHide で Windows ux 抑制 |
| 引用符 / 空白パス | 🟢 エスケープ不要 |
| パフォーマンス | 🟢 シェルプロセス 1 段挟まない |

### 却下: `spawn(cmd, { shell: true })` + 文字列引数

| 観点 | 評価 |
|------|------|
| Node.js 警告 | 🔴 `DEP0190 DeprecationWarning: Use of `shell` option is deprecated` |
| インジェクションリスク | 🔴 文字列連結でパス内に `;` や `$()` を許す |
| Windows 依存 | 🔴 PowerShell / cmd 切り替わり |
| 結論 | ❌ **DEP0190 で将来削除予定・廃止予定** |

## 📝 課題 5: 設定ファイル書き込み（データ保護）

📍 該当: `src/core/config-store.ts`

### 採用: tmp ファイル + atomic rename

```typescript
save(cfg): void {
  const error = validateClaudianBridgeSettings(cfg);
  if (error) throw new Error(error);
  fs.mkdirSync(path.dirname(this.configPath), { recursive: true });
  const tmpPath = this.configPath + '.tmp';
  fs.writeFileSync(tmpPath, JSON.stringify(cfg, null, 2) + '\n', 'utf-8');
  fs.renameSync(tmpPath, this.configPath);
  this.lastSelfWrite = Date.now();
}
```

| 観点 | 評価 |
|------|------|
| 電源断・中断 | 🟢 rename はアトミック（POSIX）／ NTFS でも close 後即 rename でリスク低 |
| 部分書き込み | 🟢 旧ファイルは無傷で残る |
| 結論 | ✅ **採用** |

### 却下: `writeFile` 直書き

| 観点 | 評価 |
|------|------|
| 中断時の状態 | 🔴 ファイル破損 → 次回 `load()` で `JSON.parse` 失敗 |
| 復旧手段 | 🔴 破損ファイルから手作業リストア |
| 結論 | ❌ **不採用** |

## 📝 課題 6: 設定ファイル監視（クロスプラットフォーム対応）

📍 該当: `src/core/config-store.ts`

### 採用: `fs.watch` + mtime polling フォールバック

```typescript
watch(onExternalChange): void {
  this.close();
  const notify = () => {
    if (Date.now() - this.lastSelfWrite < 500) return;  // 自己書込 guard
    if (this.debounceTimer) clearTimeout(this.debounceTimer);
    this.debounceTimer = setTimeout(() => onExternalChange(this.load()), 300);
  };
  try {
    this.watcher = fs.watch(this.configPath, notify);
    this.watcher.on('error', () => {
      this.close();
      this.startPolling(notify);
    });
  } catch {
    this.startPolling(notify);
  }
}

private startPolling(notify): void {
  this.lastMtimeMs = null;
  this.pollTimer = setInterval(() => {
    const mtime = fs.statSync(this.configPath).mtimeMs;
    if (this.lastMtimeMs === null) { this.lastMtimeMs = mtime; return; }
    if (mtime !== this.lastMtimeMs) {
      this.lastMtimeMs = mtime;
      notify();
    }
  }, 1000);
}
```

| 観点 | 評価 |
|------|------|
| ローカル FS | 🟢 `fs.watch` ネイティブ・低負荷 |
| SMB / ネットワークドライブ | 🟢 polling にフォールバック |
| error ハンドラ未登録 | 🟢 `error` イベントで必ずフォールバック |

### 却下: `fs.watch` のみ

| 観点 | 評価 |
|------|------|
| SMB / NAS | 🔴 `fs.watch` が `EPERM` / 無通知になることがある |
| 結論 | ❌ **不採用（環境依存で外部編集を取り逃がす）** |

## ✅ 意思決定結論

| # | 意思決定項目 | 選択 | 理由（要約） |
