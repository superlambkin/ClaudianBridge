### 2. v0.49.1 ホットフィックス（Forced reflow 嵐）

- **症状**: chat-read-highlight で `scrollIntoView({behavior:'smooth'})` の同期実行が **114ms ピークの Forced reflow を連発**し Obsidian が実質フリーズ
- **対策**: `requestAnimationFrame` 経由の `behavior:'auto'` 化（chat-read-highlight + md-read-highlight 両方）
- **結果**: ピーク **114ms → 53ms**（-53.5%）・平均 60-80ms → 32-37ms（-50%）
- **CHANGELOG**: `## [0.49.1] - 2026-09-15 — Forced reflow 嵐の緊急対応 (F-050 / F-028)`
- **GitHub Release**: https://github.com/superlambkin/ClaudianBridge/releases/tag/v0.49.1
- **GitHub Release パッケージ**: `claudian-bridge-0.49.1.zip`（720KB）

## 🎓 学び（v0.49.0 → v0.49.1）

1. **「パフォーマンス障害は 🔴 リスクとして即対応」**: v0.49.0 リリース → v0.49.1 hotfix（**1 日以内**）で Forced reflow 嵐を解消
2. **「リアルタイム観察 → 即修正」**: v0.49.1 で `[Violation] Forced reflow` を DevTools で観察 → `requestAnimationFrame` 化で根本対策
3. **「Obsidian のホットフィックス文化」**: Obsidian プラグインは 30,000+ ユーザーが即座にアップデートするため、ホットフィックスの速さが重要
4. **「JSON プラグイン分離の罠」**: ClaudianBridge 側の `installGlobalErrorHandlers` が他プラグイン（chinese-plugin-market）のエラーを拾って表示 → 切り分けが必要
5. **「手動 🔊 ボタンは設計対象外」**: F-050 は自動読み上げ（📢 報告ブロック）のみを対象。手動ボタンは対象外（設計の意図的な範囲制限）

## 🔧 障害切り分けの履歴

| 症状 | 真因 | 解決 |
|------|------|------|
| ハイライトが出ない | JS 経路は動いていた（DevTools で 4 件マッチ確認） | CSS 競合（snippet の `!important`） |
| CSS 競合 → snippet 修正 | 解決したはずだが別の問題 | rAF 化で根本対策 |
| ハイライトが「一瞬で消える」 | 読上げ完了後の deactivate で race condition | 世代トークン（`latestToken`）で誤解除防止 |
| 読上げ自体が動かない | `chinese-plugin-market` の bundle 欠落が ENOENT エラーを発生 | 同プラグインを無効化 |
| ハイライトで `「📢 報告ブロック」`が出ない | `extractReportText` の retry が 5 回失敗 → give up | MiuMiu 応答フォーマットで再生成 |
